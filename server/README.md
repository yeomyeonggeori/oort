# `server/` — Swift/Hummingbird 서버 : **이식 원본이다. 실행 대상이 아니다.**

> 상태 확정: 2026-08-03 (성재 승인) · 근거: **ADR-0145**(Swift → Rust/Axum 재작성)

## 읽기 전에

이 디렉터리는 **동작하는 서버가 아니라 계약의 원본**이다.

| | 여기(`server/`) | `server-rust/` |
|---|---|---|
| 역할 | **이식 원본** | **배포되는 것** |
| 규모 | 52 route files · **137 라우트**(유니크 경로) · 42k LOC | **65 라우트**(유니크 경로, 82 엔드포인트) · 58k LOC |
| 배포 | ❌ 안 한다 | ✅ 한다 |

**"서버가 어떻게 동작하는가"의 답은 `server-rust/`에 있다.** 여기는 **"원래 어떻게 동작하기로 했는가"**의 답이다 — 아직 이식되지 않은 라우트의 계약(권한 규칙·상태 전이·에러 문장·와이어 모양)을 확인할 때 읽는다.

## 언제 여기를 읽나

- Rust에 아직 없는 기능을 이식할 때. **계약의 정답은 여기다** — 추측해서 새로 설계하지 마라.
- Rust와 Swift의 동작이 어긋나 보일 때, 어느 쪽이 의도였는지 판정할 때.

## 언제 여기를 고치나

**거의 없다.** 이식 원본은 움직이는 과녁이면 안 된다. 새 기능은 `server-rust/`에 넣는다.

## 언제 사라지나

**라우트 parity 도달 시 일괄 삭제**(2026-08-03 성재 승인). 축별 부분 삭제를 하지 않는 이유는, 되돌아볼 원본이 조각나면 남은 이식이 근거를 잃기 때문이다.

## 아직 이식되지 않은 것 (2026-08-04 기준, 대표)

`work-controls` · `work-auto-approvals` · `workstream` · `plugins` · MCP(`InboundMCPToolRegistry` 포함) · Drive · huddles · **attachments 3경로**(uploads/complete/content) · **agent-run cancel**(`AgentRunRoutes.swift:25`).

> **불변식은 여기 있지 않다.** 단일 쓰기경로·gapless `message.seq`·RLS FORCE·provider 비유입은 59 마이그레이션(44/59가 트리거·제약·RLS)에 박혀 있고 언어 독립이다. 그래서 이 재작성이 "앱 계층 번역"으로 축소된다(ADR-0145).
