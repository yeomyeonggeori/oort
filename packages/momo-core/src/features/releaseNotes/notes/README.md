# 업데이트 소식 파일

앱 안 「업데이트 소식」(#4937)의 버전별 파일이에요. 이 폴더에는 **번호·빌드·사전 키 목록**만 있고, 글은 문구 사전에
있어요(#5054). 그래서 사전이 없는 언어는 사전의 영어 대체로 나오고(ADR-0213), 새 언어는 사전에 같은 키를 더하는 것으로
끝나요. 새 판의 소식은 승격 때 통합자가 아래 순서대로 더해요. 규칙의 정본은 `../model.ts` 머리말이고, 규칙 시험은
`../model.test.ts`의 「등록부」예요.

## 순서

1. **번호를 정해요.** 릴리스 버전(`0.1.42`), 공개일, 이 소식을 처음 담는 **폰 빌드 번호**(`phoneBuild`: 그 빌드가 실제로 받을
   번호 이하), 데스크탑 채널마다 처음 담는 버전(`desktopFrom`: release `0.1.N`, 다음 채널이 담으면 `0.1.0-next.N`도).
   붙는 규칙은 `docs/RELEASING.md` §1.
2. **글을 사전에 써요.** `i18n/catalogs/ko-KR/releaseNotes.json`과 `en-US/releaseNotes.json` 두 파일에 같은 키를, 이전 버전
   블록 아래에 더해요. 키는 `releaseNotes.v<버전 숫자>.<이름>`이에요. 버전 숫자는 점을 뺀 것(`0.1.42` → `v0142`)이고,
   사전 키는 점·밑줄·하이픈을 못 써서 이름은 영문 낱말로 시작하는 영숫자(camelCase)예요.

   | 무엇 | 키 | 개수 |
   |---|---|---|
   | 한 문장 요약 | `releaseNotes.v0142.summary` | 1 |
   | 핵심 항목(앞이 더 중요) | `…v0142.<항목>Title`(한 줄 제목, 첫 실행 창에도 나와요) · `…<항목>Changed`(바뀐 점) · `…<항목>TryIt`(이렇게 써 보세요) | 항목 1~8개 × 3 |
   | 그 밖에 바뀐 점(선택) | 주제 이름 `…v0142.<묶음>Topic` 또는 공용 `releaseNotes.topic.{conversations,attachments,notifications,agents,settings}` · 한 줄 `…<묶음>Line1`, `…Line2`… | 비워도 돼요 |

   - 「그 밖에 바뀐 점」은 설정의 버전 상세에만 나와요(첫 실행 창에는 안 나와요). 주제 묶음의 순서는 `others` 배열의 순서이고,
     묶음마다 한 줄이 1개 이상이에요.
   - 글: 해요체, 한 줄 한 문장. 「그 밖에 바뀐 점」의 줄은 줄바꿈 없이 120자 이하. 한국어와 영어가 같으면 안 돼요. 대시(`—`,
     `–`)·주소·이메일·핸들 모양은 막혀요. `{ }`와 `<`·`>`는 사전 문법이라 글에 쓰지 않아요.
   - 사전(JSON)은 `gate:copy`(코어 문자열 검사)가 보지 않아요. 대시는 등록부 시험이 막지만 과장 낱말(「원활한」·「손쉽게」
     등)은 기계가 재지 않으니 사람이 읽어요.
3. **생성물을 다시 만들어요.** `npm --prefix packages/momo-core run i18n:generate`. 한국어·영어 키가 어긋나면 여기서 멈춰요
   (`i18n:check`가 CI에서 같은 일을 해요). 생성물 3개(`i18n/generated/*.ts`)도 같이 커밋해요.
4. **버전 파일을 써요.** `notes/v0_1_42.ts`: `v0_1_41.ts`를 베껴 번호·빌드·키만 바꿔요. 키는 컴파일이 확인해요(없는 키는
   타입 오류). 항목 이름(`id`)은 키의 한 토막과 같아야 해요(`typing` ↔ `…typingTitle`).
5. **등록해요.** `notes/index.ts`의 배열에 더해요(순서는 상관없어요: 새 소식이 맨 위가 되게 화면이 스스로 줄 세워요).
6. **확인해요.** `npm --prefix packages/momo-core test -- releaseNotes`, `npm --prefix packages/momo-core run typecheck`,
   `npm --prefix packages/momo-core run i18n:check`. 등록부 시험이 잡는 것: 키 이름이 항목 이름과 버전에 맞는지, 다른 소식의
   키를 베껴 쓰지 않았는지, 빈 글·한국어와 같은 영어, 사전에만 있고 소식이 안 쓰는 키.

## 하지 않는 것

- 글을 이 폴더의 `.ts`에 직접 적지 않아요(타입이 막아요). 언어 갈래(`ko`·`en` 고르기)도 없어요.
- 브라우저 탭에서 업데이트 뒤 자동으로 띄우지 않아요(데스크탑 앱과 폰만).
