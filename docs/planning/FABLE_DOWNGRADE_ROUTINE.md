# Fable→Opus 다운그레이드 중단 루틴

> 2026-08-22 성재 지시로 성문화. 적용 대상: momo/oort의 모든 기획·검수 세션.

## 규칙

**검수·기획 세션의 모델이 Fable이 아니게 되면(한도 도달로 Opus 등으로 강하) 진행 중 작업을 중단하고, Fable에게 넘기는 핸드오프 문서를 남긴 뒤 세션을 끝낸다.** 다운그레이드된 모델로 검수·기획을 계속하지 않는다.

## 감지

- 세션 시작 시와 컴팩트 복원 직후, 시스템 프롬프트의 모델 식별자를 확인한다(`claude-fable-5`가 아니면 발동).
- 세션 도중 명시적 다운그레이드 통지를 받은 경우도 동일.

## 발동 시 절차 (순서 고정)

1. **즉시 신규 작업 착수 금지.** 비행 중인 워커가 있으면 회수만 하고 새 발사 금지.
2. **핸드오프 작성**: `docs/planning/handoffs/YYYY-MM-DD-<주제>-fable-handoff.md` — ①이 세션에서 한 일(완료/미완 구분) ②미완 작업의 정확한 재개 지점(파일·명령·상태) ③대기 중인 성재 결정 ④비행 중/회수된 워커 상태.
3. **`docs/planning/JOURNAL.md`에 항목 추가**(다운그레이드 중단 명시).
4. 진행 중이던 파일 변경은 커밋하지 않고 워킹트리에 남긴 상태를 핸드오프에 기록(단, 성재가 커밋을 지시한 경우는 예외).
5. 성재에게 중단 사실·핸드오프 경로를 마지막 메시지로 보고하고 종료.

## 예외

- 성재가 명시적으로 "Opus로 계속해"라고 지시한 경우(전례: 2026-08-19 스냅샷 42 — 한시적 Opus 검수 유지)에만 계속한다. 그 경우에도 핸드오프 문서는 남긴다.
