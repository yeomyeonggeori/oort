# oort 알파 배포 사이트 디자인 방향 (2026-07-24, Fable — 성재 발제)

> 발단: "정적 배포 사이트가 너무 밋밋하다. buzz.xyz / slack / discord 같은 사이트를 고민 중. 디스코드 히어로처럼 조금 재밌게, 다운로드·GitHub·푸터는 여명거리 느낌으로. 마스코트는 고민 중이니 우선 없이."
> 적용 대상: `dawn-kim-official.github.io/momo-alpha` (index.html 단일 페이지). publish 스크립트는 manifest JSON만 갱신하므로 페이지는 자유롭게 교체 가능(확인됨).

## 1. 아이덴티티 축 — "여명(Dawn)"

- 회사가 **Dawn**이고 성재가 "여명거리 느낌"을 지목 → **새벽 하늘 그라데이션**을 페이지의 시각 아이덴티티로 채택한다. 깊은 남색(밤) → 보라 → 지평선의 산호/호박색(동트기 직전). "에이전트와 일하는 방식의 여명"이라는 제품 서사와도 맞는다.
- 히어로 상단 = 밤하늘(깊은 남색), 푸터 = 지평선(호박색 여명 띠). 페이지 전체가 위에서 아래로 "밤 → 새벽"으로 흐르는 한 장의 하늘.
- 다크 모드가 기본 톤(새벽 하늘은 본질적으로 어두움). 라이트 모드는 "동튼 직후" 톤으로 대응.

## 3. 페이지 구조 (위 → 아래)

1. **스티키 나브**: oort 워드마크(좌) · 설치 안내/테스터 가이드/GitHub(중) · 다운로드 미니 버튼(우).
2. **히어로 (밤하늘)**: 별(CSS 점) + **떠다니는 실대화 조각 2~3개**(사람 + @김인턴 멘션 + 승인 칩 — 제품 진실 그대로, CSS-only 부유 애니메이션, `prefers-reduced-motion` 존중). 헤드라인 "에이전트가 팀원인 메신저" + 내부 알파 명시. CTA 2개: `macOS용 다운로드`(주 액션, 여명색) / `GitHub`(보조). 버전·빌드 메타는 manifest fetch.
3. **기능 3장 (박명)**: ①에이전트 = 멤버(멘션·승인·감사 원장) ②AI 연결(설정에서 provider를 GUI로) ③코드 실행 호스트(opencode·goose 동봉) — 0.0.2/0.0.3 실기능만 서술.
4. **설치 (Gatekeeper)**: 기존 3단계 유지, 번호 스텝 + 코드블록 스타일링. sha256 대조 포함.
5. **시작하기**: 서버 연결 → 초대 가입 → 에이전트 멘션 → Updates. 기존 내용 재스타일.
6. **피드백**: 채널 경로 + "시크릿·초대코드·실대화 금지" 경고 유지.
7. **푸터 (여명 지평선)**: 호박색 그라데이션 띠 위에 oort by Dawn · Apache-2.0(zip 동봉) · Releases/테스터 가이드/manifest 링크 · "내부 테스트 전용" 소자보.

## 4. 하드 룰 (momo-design-taste 웹 적용)

- 카피: 동사-우선 버튼, em-dash 0, 과장어(원활한/손쉽게/seamless) 0, 내부 어휘(Context Packet 등) 비노출.
- 색: CSS 변수 팔레트 1벌(여명 그라데이션 + 단일 액센트=호박색), 다크/라이트 `prefers-color-scheme` 대응.
- 모션: 부유 애니메이션은 장식이 아니라 "살아있는 대화" 표현 1곳(히어로)에만, `prefers-reduced-motion`에서 정지.
- 상태: manifest fetch 실패 시 "아직 게시된 빌드가 없습니다" 정직한 빈 상태 유지.
- 접근성: 시맨틱 헤딩 위계, 대비 AA(여명색 텍스트는 어두운 배경 위에서만), 키보드 포커스 링.
- 제약: 단일 파일 자급자족(외부 폰트/CDN 없음), `noindex` 유지, 시스템 폰트 스택.

## 5. 마스코트 유보 슬롯

- 히어로의 대화 조각 구성은 **마스코트가 정해지면 그 자리(히어로 우측/대화 조각의 에이전트 아바타)에 끼워 넣도록** 추상 도형(에이전트 글리프)을 임시로 쓴다. 구조 변경 없이 아바타 교체만으로 마스코트 도입 가능.
- 마스코트 방향 후보(후속 논의용): 여명/새벽 모티프(반딧불·아침새·등대) 또는 momo 발음 모티프(복숭아 등) — 결정은 성재.

## 6. 비스코프

- 공개 마케팅 사이트 아님(내부 알파 유지, noindex). 공개 전환 시 이 방향을 확장해 정식 랜딩 제작.
- 스크린샷/영상 에셋 없음(현 단계) — CSS 대화 조각이 대체. 실스크린샷은 QA 안정화 후.
