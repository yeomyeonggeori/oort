# 작업 패널 설계 — 에이전트의 사고 과정을 사람이 트래킹한다 (2026-08-04 초안)

> 발단: 성재 — *"결과만 전달하는 게 아니라 에이전트가 사고하는 과정 같은 것도 노출해서 내가 트래킹 가능하게 하는 그런 작업 패널 같은 개념은 아예 없는 거야? 설계부터 다시 봐봐."*
> 상태: **초안 — 성재 결정 D1~D3 대기.** 결정 후 ADR-0150(첨부와 번호 조정) 계열로 승격.

## 1. 실측 — 지금 무엇이 있고 무엇이 없나

| 층 | 있는 것 | 없는 것 |
|---|---|---|
| 와이어 | `agent.partial`이 **이미 나른다**: `text_delta`(부분 텍스트) · `tool_call_id/name/args`(툴 단계) · `spent_micro_usd`(비용). `agent.status`가 phase 전이를 나름 (`realtimeEvents.ts:203-225`) | — |
| 렌더 | 웹·폰 모두 그 스트림에서 **"작업 중" 헤드라인 한 줄**만 소비(`headlineFrom`) | **델타·툴 단계를 그리는 표면 0** — `text_delta` 소비처는 테스트뿐(실측). 사고 과정은 흐르는데 아무도 안 그린다 |
| 저장 | Centrifugo history(agent 네임스페이스 24h·**100프레임**) | **과정의 영속 기록 없음** — run 행에는 최종 결과·상태만. 지난 run의 과정은 재생 불가 |
| 폰 | 결과 카드(실행 결과·실패 카드) + 작업 중 배지 | 과정 표면 전무 — **D5(2026-07-27)가 의도적으로 축소**한 자리("폰은 결과만"). 성재 피드백이 이 결정을 뒤집을 근거다 |

즉 "개념이 없다"가 아니라 **파이프는 있고 화면과 기억이 없다.** 이 설계는 새 파이프를 뚫는 게 아니라 있는 파이프를 표면화+보존하는 일이다.

## 2. 제안 — 「작업 패널」 v0

**run 하나 = 패널 하나.** 타임라인의 실행 카드(또는 활동 줄의 턴)를 탭/클릭하면 열리는 패널에, 그 run의 진행이 시간순으로 쌓인다:

```
[phase] 생각 중 → 도구 호출 → 승인 대기 → 재개 → 완료      ← agent.status
[텍스트] 부분 응답이 타이핑되듯 흐름                          ← text_delta
[도구]  work.session.end(세션 A) — 승인 대기 → 승인됨(성재)   ← tool_call_* + approval
[비용]  ₩ 스냅샷 갱신                                        ← spent_micro_usd
```

- **웹**: 우측 사이드 패널(관전 표면과 동거 — 에이전트 허브·활동에서 진입).
- **폰**: 시트(활동 줄/실행 카드 탭 → 올라옴). D5의 "raw PTY는 데스크톱" 강등은 유지 — 이 패널은 터미널이 아니라 **구조화된 진행 스트림**이라 폰 폭에서 성립한다.
- 어휘: 기존 경계 유지(작업 중=열린 턴 · 승인 대기≠작업 중). 패널은 그 어휘의 "펼친 모양"이다.

## 3. 경계 결정 — 성재 몫 (권고안 포함)

| # | 결정 | 권고 |
|---|---|---|
| **D1** | **과정을 저장하는가.** A안: 휘발 관전만(라이브+Centrifugo 24h 히스토리 한도) — 서버 무변경, 지난 run은 과정 없음. B안: 과정 이벤트를 DB에 보존(새 테이블+보존기간+**프라이버시 경계** — "실행 내용 미보관" 보안 문안과 충돌 검토 필요) | **A안으로 v0** — 화면부터 세우고, 보존은 실사용에서 "지난 run 과정이 필요했다"가 실증되면 B를 ADR로. 저장은 되돌리기 어려운 경계라 늦게 여는 게 맞다 |
| **D2** | 표면 순서 | **웹 먼저**(패널 반나절 거리 — 데이터가 이미 온다), 폰 시트는 그다음 배치. 두 클라 판정 로직은 core로(이번 배치들 규율 그대로) |
| **D3** | 이름 | 「작업 패널」(성재 어휘 채택). 관전 축의 심화로 분류 — 로드맵 축 언어 유지 |

## 4. 선행·주의

- **게이트웨이 직송 경로에 성공 종료 프레임 부재**(#994 2R 발견, 선존재) — 패널이 그 경로 run에서 "끝났는데 열려 있음"으로 보일 수 있다. 패널 착수 전 수리 필요(후속 큐에 있음).
- 100프레임 히스토리 한도: 긴 run은 라이브 진입 시 앞부분이 잘린다 — v0는 "잘린 지점부터"를 정직하게 표기(A안의 알려진 한계로 문서화).
- `tool_call_args`는 민감할 수 있다(경로·프롬프트) — v0 패널은 **도구 이름+상태만**, args는 접힘+명시 펼침(taste 규율).
