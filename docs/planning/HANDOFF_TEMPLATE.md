## Goal
사용자가 확인할 결과와 완료 지점.

## 계약과 범위
관련 Issue/Accepted ADR 링크. 수용기준은 여기 또는 이슈 한 곳에 두고 다른 곳은 링크한다.
허용 파일·지킬 계약·범위 밖. 단순한 작업은 별도 패킷 없이 이슈에 작성한다.

## 구현에 필요한 맥락
필요한 파일/심볼, 실제로 확인한 함정, 다른 작업과의 의존/통합 순서.
방법을 강제해야 하는 이유가 있는 경우만 절차를 적는다.

## 검증과 전달
변경에 맞는 검증 등급·실행 환경·관측할 결과. 미검증 범위와 외부 의존.
worker는 PR/검증 증거를 인계하고, orchestrator는 요청된 완료 지점까지 계속한다.
공통 명령·권한은 AGENTS와 개발 검증 런북을 참조한다.

## 체크포인트
현재 commit / 한 일 / 마지막 검증 / 다음 행동 / 실제 막힘 / run 식별자.
계약 이탈이 있으면 내용과 필요한 결정을 기록한다.
