# goal RN-C5 — 메시지 액션 · 스레드 · 검색 (RN v0 대화 완결)

너는 momo(제품명 oort) 레포의 구현 worker다. 이 문서가 유일한 지시서.
**base = `track/engine`**. 워크트리 `~/projects/momo-tracks/momo-worktrees/RN-C5-actions`(브랜치 `feat/RN-C5-actions`, 생성됨).

발단: RN 대화 표면이 **읽기·받기·보내기**까지 섰다(PR #968 — 앵커 0px/1.3px, 컴포저-키보드 0px, 한글 동기 입력 증명). 이 배치가 **v0 대화를 완결**한다.

## 0. 범위
1. **메시지 액션** — 반응 토글 · 답글 · 수정 · 삭제. **폰이므로 길게 누르기(long-press) 시트**가 진입점이다(hover 는 터치에 존재하지 않는다).
2. **스레드** — 답글 목록 보기·쓰기.
3. **메시지 검색** — 서버에 이미 있다(`GET /v1/workspaces/{ws}/search/messages`).

**범위 아님**: 허들 · 터미널(D5 강등) · 설정 · 채널 관리.

## 1. 규율
`.env`·자격증명 금지 · **서버 코드·`schema_v0.sql` 수정 금지** · **docker 금지** · **실서버 접속 금지**(실왕복은 오케스트레이터) · **`clients/web`·`clients/iOS`·`clients/mobile-spike` 수정 금지** · `expo prebuild`·EAS·`android/` 금지 · 커밋은 새 커밋만 · **PR 후 STOP**.
**`packages/momo-core` 는 읽기 우선.** 고쳐야 하면 최소로 + 사유, `gate:purity` 가 판정한다.

## 2. 웹이 이미 답을 만들어 뒀다 — 읽고 따라가라
같은 기능을 웹이 **B11(메시지 액션)·B12(검색)**에서 구현했고, **design-review 2라운드를 거치며 실측으로 고친 것들**이 있다. 다시 발명하지 말고 그 결론을 가져와라.

**웹에서 반드시 승계할 것**
- **행당 탭 스톱 1개 이하** — 웹은 행마다 6개를 만들었다가 Blocker 급으로 되돌렸다. 모바일은 시트가 그 역할을 하므로 자연스럽게 지켜지지만, 칩·앵커까지 합쳐 세어 봐라.
- **오류 문구는 상태코드 → 한국어 문장 매핑**(`actionCopy` 계열). 와이어 문자열이 화면에 닿으면 안 된다. 409(반응 상한)처럼 **다음 행동까지** 말해 주는 문구를 유지해라.
- **낙관적 되돌림이 사용자에게 보인다** — 실패하면 칩이 되돌아가고 **이유가 그 행에** 뜬다. 토스트 아님.
- **대소문자 접기는 한 곳에서**(`reactions.ts`) — 서버가 반응 id 를 대문자로 낸다. 이건 **Swift 서버 전역 기본값이고 `openapi.yaml` 이 비준한 계약**이라 고치는 게 아니라 접는 것이다.
- **한 단계 스레드 규칙** — 답글에는 「답글 달기」가 뜨지 않는다.
- **삭제는 tombstone** — 목록에서 조용히 사라지면 seq 구멍처럼 보인다. 단 **본문과 같은 무게로 렌더하지 마라**(웹이 그 지적을 받았다).
- **수정/삭제는 본인 메시지만** 노출(서버가 정본, 클라는 노출 제어).

**서버 계약**(웹이 이식해 둔 것 그대로): `PATCH …/messages/{id}` · `DELETE …/messages/{id}` · `PUT/DELETE …/messages/{id}/reactions/{emoji}` · `GET …/channels/{ch}/reactions` · `GET …/messages/{root}/replies`.
검색: `?q=&limit=&cursor=`, `q` 2자 미만 400, `limit` 1..50, 마지막 페이지는 `nextCursor` **키 자체가 없다**, 결과는 **내가 속한 채널로 한정**된다.

## 3. 실측 제약 (어기면 깨진다)
- **입력 상태는 동기**다 — 검색 입력칸·수정 편집기·스레드 컴포저 **전부**. 비동기 반영은 한글을 깬다(실측).
- **리스트에 `inverted` 금지.** 스레드·검색 결과 목록도 같다.
- 스크롤 위치 보존이 필요한 목록은 **측정으로 증명**해라(기준 ≤2px).
- **길게 누르기는 스크롤과 싸우면 안 된다** — 웹 배치에서 "스크롤은 누르기가 아니다" 방어가 **죽은 코드**였던 전례가 있다(거리 판정이 한 번도 안 돌았다). 이동 임계 판정을 **테스트로** 못박아라.

## 4. 모바일 UX
44px 터치 타깃 · 안전영역 · 가로 스크롤 0 · 시트에 **보이는 닫기 경로** · 한국어 사용자 문장 · 로딩/빈/오류 상태 전부.
**폰에서 액션의 존재를 알 수 있어야 한다** — 웹이 "폰에서 가시적 진입점 0개"로 지적받았다. 과설명 없이 발견 가능하게.
