## 2. #1798 수리 계약 (워커 브리프의 핵심 — 검수 §4.2 처방 승계)

- 도메인 층(트랜잭션 안)에서 **대상 role 조회 + 계층 판정**: `행위자 role > 대상 role`. owner만 owner/admin 대상 발급 가능, admin은 member/guest만. 라우트 층 단독 검사 금지(우회 경로 방지).
- **자기 자신 리셋 차단**(본인 변경 경로가 따로 있음).
- **red proof 필수 — 행위자×대상 매트릭스**: admin→owner **403** · admin→admin **403** · owner→admin 허용 · owner→member 허용 · self **403**.
- #1799 초대 revoke의 같은 계열 점검(admin이 owner 발급 초대를 취소 가능한가 — 검수 §4.3은 문제없음 판정이나 매트릭스로 재확인).
- ADR-0128 D2가 이미 Accepted 규칙이므로 **신규 결재 불요** — 기존 정본의 적용이다.
