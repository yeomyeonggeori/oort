너는 momo(제품명 oort) 레포의 구현 worker다. 이 문서가 유일한 지시서.
**base = `track/engine`**. 워크트리 `~/projects/momo-tracks/momo-worktrees/RN-C4-conversation`(브랜치 `feat/RN-C4-conversation`, 생성됨).

발단: v0 셸이 랜딩했다(PR #967 — 인증·사이드바·인박스, 모바일 테스트 176). 사이드바에서 채널을 고르면 열리는 **대화 화면 자리표시자**(`clients/mobile/src/screens/ConversationScreen.tsx`)를 **네가 통째로 대체**한다.

**여기가 스파이크 제약이 실제로 물리는 곳이다.** 실기기 실측으로 산 규칙이라 어기면 한글이 깨지거나 스크롤이 튄다. 먼저 `docs/planning/2026-08-02-rn-spike-report.md` 를 읽어라.

## 0. 이번 배치의 범위 — **읽기 · 받기 · 보내기**
1. **타임라인 읽기** — 메시지 목록, 과거 로드(위로), 에이전트 실행 결과 카드, 「수정됨」·삭제 tombstone, 스레드 롤업 표시, 반응 칩 **표시**(누르는 건 다음 배치).
2. **실시간 수신** — centrifuge 구독으로 새 메시지가 들어온다. 스캐폴드가 남긴 `RealtimeHandle`(미구현)에 **이제 호출자가 생겼다.**
3. **컴포저 전송** — 텍스트 입력 → 전송 → 낙관적 반영 → 서버 확인/실패 되돌림. 멘션 자동완성.

**이번 범위 아님**: 메시지 액션(반응 누르기·답글·수정·삭제) · 스레드 패널 · 검색 · 허들 · 터미널(D5가 강등).

## 2. 절대 어기면 안 되는 실측 제약 3개

### 2-1. 컴포저 `value` 는 **동기**다 (게이트 1 실측)
`setTimeout`·큐·네트워크·스토어를 거쳐 value 가 되돌아오는 구조를 만들면 **한글 자모가 합쳐지지 않는다**(실측: `안녕하세요` 가 `ㅇㅏㄴㄴㅕㅇㅎㅏㅅㅔㅇㅛ` 로 남았다). 낙관적 로컬 상태를 **동기로** 유지하고 서버 왕복은 **별도 경로**로 둔다.
**특히 멘션 자동완성**: 매 keystroke 마다 후보 목록이 리렌더되는 구조인데, 스파이크 C 케이스가 정확히 그 부하를 조합 중에 걸어 **통과**했다. 단 그 통과는 **동기 value 전제**였다.

### 2-2. 타임라인에 `inverted` 를 쓰지 마라 (게이트 5 실측)
인버티드에서 새 메시지 도착 시 읽던 위치가 **46~91px 튀었고**(FlatList/FlashList v2/Legend 3자 모두), **정방향에서는 0px** 이었다. 정방향으로 렌더하고 최신을 아래에 둔다.
- **새 메시지 하단 삽입은 정방향에서 구조적으로 0px** 이다(내용이 아래로만 자란다).
- **과거 프리펜드(위로 로드)에는 명시적 위치 보존이 필요하다.** 정방향에서도 Legend 가 25px 움직였다. 웹이 react-virtuoso `firstItemIndex` 를 삽입 개수만큼 줄여서 푼 그 문제이며(`clients/web/src/features/timeline/Timeline.tsx` 의 주석을 읽어라 — **페이지 크기로 보정하면 안 되는 이유**까지 적혀 있다), RN 에서도 같은 종류의 보정이 필요하다.
- 리스트 구현 선택은 네 판단이되 **위 성질을 측정으로 증명**해라(앵커 이동 px). 게이트 5 하네스(`clients/mobile-spike/src/gate5_list/`)를 **읽어서 방법을 참고**해라(그 디렉터리를 수정하지는 마라).

### 2-3. 커스텀 스킴 URL 은 폴리필 경유 (게이트 2 실측 — 이미 배선됨)

## 3. 반드시 코어에서 오는 것
메시지 정렬·병합(**`timeline/model.ts` 의 seq 순서 병합**)·스레드 롤업·아티팩트 판정·에이전트 카드 모델·오류 문구·`clientMsgId` 생성 — **전부 `@momo/core` 에 있다.** RN 에서 다시 짜지 마라. 없으면 왜 없는지 확인하고 PR 에 적어라.
**주의**: 코어의 `crypto.randomUUID()` 는 RN 에 전역이 없어 스캐폴드가 폴리필로 막아 뒀다. 전송 경로가 그 폴리필을 실제로 지나는지 확인해라.

## 4. 실시간 (D4)
- centrifuge-js 를 코어 인터페이스에 주입. **리플레이 게이트**(끊김 후 `recovered`/`hasRecoveredPublications` 로 증분 복구)가 RN 에서도 성립하는지 확인 — 스파이크 게이트 3 이 이미 25/25 · missing 0 으로 증명했으니 **같은 성질**을 앱에서 재현해라.
- 백그라운드 정책: **15초 유예 후 끊기**, 포그라운드 복귀 시 재개, 네트워크 타입 전환은 강제 재연결.
- **알려진 서버측 제약(수정하지 마라)**: RN 의 WebSocket 은 `Origin` 헤더를 보내고, 레포의 Centrifugo `allowed_origins` 로는 **LAN/localhost 가 거절**된다. 증상은 소켓이 열리지 않은 채 `transport closed` 무한이다. **로컬 스텁으로 증명하고** 이 사실을 PR 에 적어라.
