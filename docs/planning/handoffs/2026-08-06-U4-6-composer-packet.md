## U4-6W (웹 — #1102)
- **U4-f 컴포저**: ①초안 보존(채널 전환·재방문에 생존 — 저장 위치·수명 정책 명시) ②오프라인 전송 비활성(정직 문구 — 승인 카드 오프라인 결 전례) ③auto-grow를 기존 `useAutoGrow` 재사용으로 교체(감사 M-7). **첨부는 범위 밖**(ADR-0151 승인 대기 — 자리 경쟁 예방은 U4-2 H-2 이관분 참조).
- **M-3 문장 옷**: 승인 카드 세 문장(영수증=방금 한 되돌릴 수 없는 행동 / 안내 / 오프라인) 시각 위계 분리 — 영수증 격상. 웹 먼저 옷을 정하고 폰이 같은 위계 소비(코어에 tone 판정 두는 것 검토).
- **D-2 색 계약**: 안읽음 경계의 의미("경계를 그리는 색")를 코어 계약으로 — 값이 아니라 역할 명세(웹 accent/폰 warn 현행 유지하되 계약 테스트로 우연을 의도로). U4-4R W-2 전례(가드가 실표를 봄).
- **C-1 seq 어휘**: `재연결됨, seq N까지 복구` → 사람 어휘(코어 divider 수정 — 양 클라 동시 반영. "복구"의 정직성 유지하며 내부 어휘 제거. 낭독 라벨도 함께).
- **deleted-fold 승격**: #1100의 폰 로컬 `deletedFold.ts` 규칙을 코어로 + **웹 동일 결함 확인**(웹 타임라인의 연속 삭제 묘비 팽창 여부 실측 — 있으면 소비, 없으면 근거 기록).

## U4-6M (폰 — #1103)
- **U4-f 폰**: 초안 보존·오프라인 비활성(웹과 같은 정책 — 코어 판정 공유 검토)·컴포저 성장 정책(현행 실측 후 필요분만).
- **U4-d 아바타(H-11)**: `avatarUrl` 경로 개통 + 폰 아바타 신설. 감사가 "CSP·타입까지 건드려 별도 티켓 권장"한 자리 — **타입/계약은 웹 워커가 코어에 먼저**, 폰은 렌더. 이니셜 폴백·에이전트/사람 구분(색·모양) 포함. 크기·배치는 감사 H-11 근거.
- **삭제 접기 코어 소비**: 승격분으로 로컬 `deletedFold.ts` 대체(문자열·규칙 동일성 단정).
- **M-3 폰 대응**: 카드 문장 옷 — 웹이 정한 위계 소비.
