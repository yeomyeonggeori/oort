## Goal A (#1070) — 시각·위계: 인용 규정선·코드 색·배너
- H-2: 인용 규정선 `color.accent` → 중성(웹 판: `line-strong` 계열). 폰 고유 근거 3(배경 1.08:1이 범위 못 닫음·`surface`=눌림 색·accent=보내기/내 반응과 3중 의미) — 배경 처리는 웹의 "되돌림" 교훈 참조(고도 띠는 인용 무게를 올린다). 수리 후 그 값을 재는 단정(웹 gate:quote `[color]` 방식의 RN 판 — 하네스 캡처+스타일 단정).
- H-4: `MessageBody` 코드 블록 `color` 박음 제거 — 상속(같은 파일 인라인 코드 규칙·웹 CODE_CLASS 선례). 낙관 메아리에서 코드까지 흐려지는지 단정.
- H-5: 「원본은 더 위」 배너를 `FailureBanner`→`NoticeBlock`(atoms에 기존재 — "실패가 아닌 사실 진술"용) + 표시 위치/소멸 재고(상단 고정·닫기 없음 문제). 최소판: NoticeBlock 전환+점프 성공 시 자동 소멸.
- M-3: 복사 영수증 규칙 통일(코드=「복사됨」 1.5s vs 시트=무언 — 한쪽으로) · N-1(`#0b0d11` 비토큰) · N-2(스케일 밖 간격).

## Goal B (#1071) — 접근성·타깃
- H-1: 행=접근성 원소 1 규칙 **유지**하면서 신규 행 내 컨트롤 4(인용 점프·코드 복사·본문 링크·아티팩트 URL)를 **로터 액션으로 등재**(`MessageRow.tsx:794-799` 목록 확장 + `onAccessibilityAction` 분기). 링크 다수·코드 다수 행의 액션 폭발은 "첫 항목+시트 폴백" 같은 절충 허용 — 판단 기록.
- M-1: 마크다운 경로 `selectable` 배선(평문 경로와 동등) — 마크다운 낙관 메아리의 텍스트 추출 경로 복원(BL-2 잔여).
- M-8/M-9: 인용 블록·코드 복사 44pt 확보(`hitSlop` 우선 — 리뷰 계산 41/40pt를 실측 확정 후). M-2: 「메시지 복사」→동사형(이웃 항목과 결). M-7(시트 스크롤)은 Dynamic Type 실측 후 필요 시 — 아니면 "확인 필요 해소" 기록만.
- 검증: VoiceOver 실기 불가 시 접근성 트리 덤프/단정으로 대체하고 한계 명기.

## Goal C (#1072) — 「작성 중」 안정화
- H-3: 자리 예약 — 남의 키가 엄지 밑 컨트롤을 못 움직이게(웹 H-2 판정의 폰 이행 — 그 판정의 근거가 폰이었다). 예약 높이는 1줄 고정(웹과 동일 트레이드오프 — #1065 묶음과 정합 유지).
- M-4: `typingSegments` 소비 — 사람 줄 이름에 자기 표지(ink 강조), TypingBar "문장 안 짓기" 규율은 세그먼트 배열 소비로 유지.
- M-5: 컴포저 위 액세서리 스택 정리 — 작업중/작성중 인접 배치(사이 2줄 개입 해소), 4겹 상한 재고. 웹과의 순서 반전은 **이번엔 기록만**(두 클라 순서 통일은 별도 결정 — 이탈 절에).
- M-6 부분: 작성중 줄이 `textFaint`(AA 미달) — 이 줄만이라도 `textMuted`로(토큰 전면 재조정은 U2 소관, 여기선 용례 이동만). N-4: iOS 무동작 `accessibilityLiveRegion` — 웹의 "일부러 뺐다"와 정합하게 제거+주석 정정.
