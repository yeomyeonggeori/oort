## 1. [Blocker] 760x480에서 상세 `dd` 폭이 0px — 사용자 텍스트가 통째로 사라진다

실측: 상세 컬럼 **200px**인데 `dt`가 `w-pane-sm`(192px) `shrink-0` → **`dd` 폭 0**. "관리 주체: 곽성재", "현재 작업: 작업 중"이 **화면에서 소멸**. 검색 placeholder도 중간 절단("기억 내돌").
**760x480은 이 레포가 스스로 세운 바닥**이고(MOMO-610 dialog-panel·MOMO-628 설정 실측), 기본 크기에서 잘린 사용자 텍스트는 항상 Blocker다.

→ **work-pane이 900px 아래에서 한 것과 같은 전환**을 따르라(로스터/상세 단일 컬럼 또는 로스터 접기). 좁은 컨테이너에서 `dl` 라벨 축이 **고정폭이 아니게**. 깨지는 조건은 "컬럼 < 2× 라벨 폭"이다 — 픽셀을 외우지 말고 그 관계를 없애라.

## 2. [Blocker] 긴 에이전트 이름에서 섹션 탭이 음절 단위로 낙하
