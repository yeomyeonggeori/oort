# goal QA-flake — `capture:design` 플레이크 제거 (증거 파이프라인 복구 마무리)

너는 momo(제품명 oort) 레포의 구현 worker다. 이 문서가 유일한 지시서.
**base = `track/engine`**. 워크트리 `~/projects/momo-tracks/momo-worktrees/QA-capture-flake`(브랜치 `feat/QA-capture-flake`, 생성됨).

발단: `npm run capture:design`(웹 캡처 게이트)이 **비결정적으로 실패**한다. 이건 사소한 불편이 아니다 — **design-review 의 증거 파이프라인**이고, 이미 두 번 대가를 치렀다:
- B11 리뷰어는 캡처가 없어 **게이트를 직접 재실행**해야 했다.
- P3 워커는 하네스를 **일시적으로 끊고** 캡처를 찍어야 했다.

그리고 **플레이크 게이트는 "초록 나올 때까지 재실행"을 학습시켜 게이트를 죽인다.** 그게 이 배치가 존재하는 이유다.

## 0. 실측된 사실 (여기서 출발해라)
- 오케스트레이터 실측: 2회 실행 중 **1회 실패**. 실패 지점 = `Error: [스크롤] turn-failure를 6번 시도해도 화면에 올리지 못했다` (`clients/web/scripts/capture-screens.mjs` 의 `scrollTimelineRowIntoView`).
- 다른 워커 실측: base 커밋에서 **4회 중 1 PASS / 3 FAIL**, 그리고 **서로 다른 비결정 실패가 2종**이었다. 즉 원인이 하나가 아닐 수 있다.
- 하네스 `capture-screens.mjs:467` 근처에 **이미 같은 증상을 적어 둔 주석**이 있다(`turn-failure` 를 못 찾고 죽었는데 증상은 200줄 뒤에서 났다는 취지). 먼저 읽어라.
- 이 실패는 **RN-C1(momo-core 추출) 이전부터 존재**한다. 추출이 원인이 아니다.

## 1. 규율
`.env`·자격증명 금지 · **서버 코드·`schema_v0.sql` 수정 금지** · **docker 실행 금지** · **`clients/mobile`·`clients/mobile-spike`·`packages/momo-core` 수정 금지**(다른 배치가 소유한다) · 커밋은 새 커밋만 · **PR 후 STOP**.

## 2. 할 일
1. **원인을 밝혀라, 증상을 덮지 마라.** `waitForTimeout` 을 늘리거나 재시도 횟수를 키우는 것은 **금지**다 — 그건 플레이크를 더 느리고 더 드물게 만들 뿐이고, 다음 사람이 같은 자리에서 다시 만난다. 왜 그 행이 가상화 창에 안 올라오는지, 왜 실패가 200줄 뒤에서 표면화되는지 코드로 설명해라.
2. **실패가 났을 때 그 자리에서 죽게 만들어라.** 지금은 원인 지점과 증상 지점이 떨어져 있어 진단이 어렵다. 실패 메시지가 **무엇을 기다렸고 그때 화면에 무엇이 있었는지** 말해야 한다.
3. **두 번째 비결정 실패도 찾아라.** 다른 워커가 "서로 다른 실패 2종"을 봤다. 하나만 고치고 끝내지 마라.
4. **연속 실행으로 증명해라.** 고친 뒤 **최소 5회 연속 exit 0**. 실행 로그를 PR 본문에 붙여라. 5회가 우연일 수 있으면 더 돌려라.

## 3. 판단이 필요할 수 있는 것
`turn-failure` 프레임의 피사체가 **이 빌드에 여전히 존재하는지** 먼저 확인해라. P3 배치에서 인박스 프레임이 정확히 그 이유로 죽었다(제품이 정직하게 접히면서 기다리던 행이 사라짐). 피사체가 없어졌다면 **기다림을 고치는 게 아니라 프레임을 현재 제품 사실에 맞춰야** 한다 — 그때는 무엇을 왜 바꿨는지 적어라.

## 4. 검증
- `npm run capture:design` **5회 연속 exit 0**(로그 첨부).
- `clients/web` 의 `typecheck`·`lint`·`test`·`build` 통과, **테스트 수 불변**.
- 다른 게이트(`gate:shell`·`gate:wire`·`gate:csp` 등) 통과.
- **회귀 0**: `packages/momo-core` 의 `test`·`gate:purity` 수치 불변.
