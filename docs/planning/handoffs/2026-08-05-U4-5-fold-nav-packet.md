## U4-5W (웹 — #1096)
- **U4-e 접기**: 긴 산문·코드펜스·에이전트 카드 값에 접기 예산 — 같은 폴더 `ArtifactCard`의 `EAGER_LINE_BUDGET` 패턴 재사용(새 기계 발명 금지). 접힘 상태가 "이게 전부가 아니다"를 정직하게(줄 수를 알면 「N줄 더」, 모르면 겸손한 표기 — N-3 전례). red proof: 접기 임계 되돌리면 빨강.
- **U4-j 웹 항법**: 「최신으로 점프」 + 아래 새 메시지 배지 — `VirtuosoHandle`이 연결만 안 된 상태(감사 실측). followOutput 상태와의 상호작용(읽던 중 새 메시지 = 배지, 바닥이면 자동). 
- **W-4**: hover 시각 발견 가능성 — 정지 상태 단서(재량: 그룹 머리 상시 시각이 이미 가르치므로 최소 개입 우선) + **액션 없는 행의 키보드 경로**(읽기 전용 마운트에서 포커스 가능한 자식 0 문제 — `<time>`은 DOM에 있으므로 시각적 focus 경로만).
- 검증: 스위트+typecheck+lint 총계 · gate 확장 또는 신설(+기존 gate:borders/typing/quote 무회귀) · 캡처 light/dark · red proof ≥2 · PR "Closes #1096"·이탈 절·STOP.

## U4-5M (폰 — #1097)
- **U4-i 위생**: ①탭 타깃 44pt 잔여 전수(감사 M-1 계열 — hitSlop 선례) ②낙관 에코 여백 — **PendingRow가 빈 `styles.row`에 자식 직결로 좌우 여백 0**(#1093 관찰, rowInner 규율로 편입) ③삭제 메시지 접기(M-13의 삭제 행 팽창) ④하드코딩 hex→토큰(M-13/M-14 — `#0b0d11`류 잔재 전수, U4-2의 `#1a2740`·`#241d0f`류 포함 가능한 만큼. 토큰에 없는 값은 이름 신설이 원칙 — `--spacing-row` 전례).

- **M-2 기준선**: 그룹 머리 시각이 작성자 줄 baseline에 참여하게(2~3pt 어긋남 해소) + `lineHeight: 22` 스케일 밖 값 정리.
