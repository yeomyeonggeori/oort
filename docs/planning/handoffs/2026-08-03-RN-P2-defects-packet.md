## 결함 1 — 키보드가 여전히 늦다 (**두 번째 보고**)
> 성재: "1 여전히 느려."

지난 배치가 원인 하나를 걷어냈다(=`configureNext` 가 다음 커밋을 무장시켜 `willShow → setState → render → commit → 애니메이션` 순서였던 것). 그런데 **여전히 느끼신다**. 그리고 그 배치의 자체 측정도 **기준 미달로 FAIL 로 남아 있다**: 첫 이동 **71–85ms**(기준 ≤17ms) · 도착 **352ms**(기준 ≤300ms).

**오케스트레이터가 확인한 남은 원인 후보(검증하고 고쳐라, 그대로 믿지 마라)**:
`src/lib/useKeyboard.ts:99` 가 **`useNativeDriver: false`** 이고, 같은 파일이 값을 **`paddingBottom`**(레이아웃 속성)에 물리라고 적어 뒀다. 레이아웃 속성은 네이티브 드라이버를 못 쓰므로 **애니메이션 매 프레임이 JS 스레드를 거친다.** 컴포저는 마침 조합 중 멘션 재필터로 JS 를 쓰는 자리라 더 나쁘다.
→ **`transform: translateY` 로 옮기면 `useNativeDriver: true` 가 가능하다.** 그 경우 레이아웃이 안 변하므로 리스트 높이·`contentInset` 을 어떻게 맞출지 함께 풀어야 한다(리스트를 같이 밀지, `contentInset`/`scrollIndicatorInsets` 로 처리할지는 네 판단).

**요구**:
- 첫 이동 **≤17ms**(한 프레임), 도착 **≤300ms** 를 **실제로 달성**해라. 못 달성하면 **기준을 늘리지 말고 FAIL 로 남기고**, 무엇이 남았는지 적어라(지난 배치가 그렇게 한 것은 옳았다).
- **JS 스레드를 일부러 바쁘게 만든 상태에서도** 재라. 실사용은 조합 중 멘션 필터가 도는 상태다 — 한가한 JS 에서만 빠른 애니메이션은 실기기에서 다시 늦어진다.
- 애니메이션 중 **컴포저와 키보드 상단 간격 0px** 유지(지난 배치 성질, 되돌리지 마라).

## 결함 2 — 답글이 답글로 보이지 않는다
> 성재: "답글쪽은 아직 뭔가 부족한 거 같아. 답글을 달았는데, 답글 모양 아이콘과 함께 별도로 안 보이는 거 같아."

지금은 스레드 패널(`ThreadPanel.tsx`)과 롤업(`threadRollup`)은 있는데, **타임라인 본문에서 답글이 답글로 식별되지 않는다.** 사용자가 답글을 달고 나면 그 답글이 **어디에도 눈에 띄게 나타나지 않는다**는 것이 보고 내용이다.

**확인하고 설계해라**(웹이 어떻게 하는지 먼저 읽어라 — `clients/web/src/features/timeline/`):
- 답글을 단 뒤 **그 답글이 어디에 나타나는가.** 루트 아래 롤업만 늘어나는가? 답글 자체는 스레드를 열어야만 보이는가? 그렇다면 사용자가 "내가 쓴 게 사라졌다"고 느끼는 것이 당연하다.
- **답글임을 알리는 표식**(부모 인용/아이콘/들여쓰기 중 무엇이든)이 필요하다. 웹 규약과 어긋나지 않게 하고, 없으면 **왜 없는지** 확인해서 적어라.
- **한 단계 스레드 규칙**(답글에는 「답글 달기」가 없다)은 유지.
- 내가 쓴 답글은 **쓰자마자 보여야** 한다 — 결함 원리가 "내가 보낸 메시지가 아래로 숨던 것"과 같은 계열이다(내 행동의 결과는 내 눈에 보인다).

## 결함 3 — 서버에 못 닿는 시작이 로그인 화면을 띄운다 (P1, 게이트 배치가 넘김)
자격증명은 **살아남는다**(코어 수정 완료). 그런데 화면이 틀렸다 — **캐시를 보여주는 화면이어야 하는데 로그인 화면이 뜬다.**
원인 보고: 코어가 `unreachable` 에 더 이상 throw 하지 않아 `src/session/useSession.tsx` 의 `.catch` 가 영영 안 돌고 `restoreUnreachable` 이 false 로 남는다. `authGate.ts` 가 **실패 모드 4번**으로 명시해 둔 상황이다.
- 코어의 `refreshSessionOutcome()` 이 `"unreachable"` 을 **이미 구분해서 준다.** 호스트가 그걸 읽어 분기해라.
- 오프라인 시작은 **로그인 화면이 아니라** 캐시된 내용 + "연결되면 이어집니다" 류의 정직한 상태여야 한다(문구는 한국어 사용자 문장, 내부 용어 금지).
- **`npm run gate:session` 이 이 상황을 note 로만 기록하고 있다**(`gate=signedOut expired=false`). 고친 뒤 그 note 를 **단언으로 승격**해라 — 회귀 방어가 이 배치의 산출이다.
