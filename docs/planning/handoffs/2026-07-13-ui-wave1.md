## MOMO-357 — 앱 셸·사이드바 Slack급 정비 `[swift/macos-ui]`

문제: 현 사이드바는 기능 나열(작업함/채널/멤버/개발 도구)이고 밀도·계층·hover 문법이 데스크톱 메신저 기준 미달. 개발 도구 섹션이 1급 자리를 차지한다.
방향:
1. 섹션 계층 재정비 — 워크스페이스 헤더(이름+계정), 채널, DM 자리(비어도 문법 확보), 멤버. "개발 도구"/"에이전트 승인함"은 하단 유틸리티 영역 또는 워크스페이스 메뉴로 강등.
2. 행 문법 통일 — 높이/패딩/타이포 토큰화, hover 시에만 액션 노출(현재 상시 노출된 −/@/프로필 버튼 정리), 선택 상태 대비 강화.
3. presence 점: real-server 세션에서 실상태에 안 묶인 `.online` 하드코딩 점을 숨기거나 중립 처리(MOMO-354 design-review Medium ① 해소, ADR-0104 전까지).
4. 사이드바 접기/리사이즈 문법과 최소 폭 정책.

## MOMO-358 — Cmd+K 퀵 스위처 `[swift/macos-ui]` (357 랜딩 후 스폰)

문제: 키보드 우선 내비게이션(P11) 부재 — 채널 전환이 마우스 전용.
방향:
1. `Cmd+K` 오버레이 — 채널/멤버 fuzzy 검색, ↑↓/Enter/Esc, 최근 채널 우선 정렬. Raycast 문법(즉시 뜨고 즉시 닫힘, 첫 키 입력까지 지연 0).
2. `Cmd+1..9` 채널 바로가기, `Cmd+[`/`Cmd+]` 히스토리 이동.
3. 스위처는 roster SoT 데이터만 사용(멘션 후보와 동일 술어) — 미초대 멤버는 후보에 안 뜬다.
4. 키보드 단축키 도움말 표면(`Cmd+/` 시트 또는 설정 탭).

## MOMO-359 — 메시지 타임라인 밀도·그루핑 `[swift/macos-ui]`

문제: 메시지가 개별 카드로 떠 있어 밀도가 낮고 스캔이 어렵다. 연속 발화 그루핑·날짜 구분선·hover 액션 문법 부재.
방향:
1. 연속 작성자 그루핑 — 같은 작성자 연속 메시지(간격 임계 이내)는 아바타/이름 1회 + compact 행. `message.seq` 순서 권위 불변.
2. day divider + 신규 메시지 진입 시 스크롤 정책(하단 고정 vs 위치 유지) 명시.
3. hover 액션 바(복사/스레드 자리/이모지 자리 — 실기능 없는 버튼은 넣지 않는다, 있는 기능만).
4. 에이전트 메시지 문법 유지 — AGENT 배지·status/partial 스트림 카드(MOMO-350)와 그루핑이 충돌하지 않게.
5. 타임스탬프: 그룹 첫 행 상시 + compact 행은 hover 노출.
