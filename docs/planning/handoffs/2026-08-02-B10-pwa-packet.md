# goal B10 — PWA: 홈 화면 설치·전체화면 (RN 앞의 임시 다리)

너는 momo 레포의 구현 worker다(Claude Opus 5). 이 문서가 유일한 지시서.
**base = `track/engine`**. 워크트리 `~/projects/momo-tracks/momo-worktrees/B10-pwa`(브랜치 `feat/B10-pwa`, 생성됨).
**위치 규정**: 이 배치는 **ADR-0137(RN 채택, Accepted)을 대체하지 않는다.** RN v0가 나오기 전까지 폰 사용자의 체감을 메우는 임시 다리다. PR 본문에 이 문장을 명시할 것.
발단: 성재 iPhone 실사용 — Safari URL 바가 컴포저를 가리고 앱 같지 않음.

## 0. 규율
`.env` 금지 · **PR 후 STOP**(amend/force-push 금지) · 대상 `clients/web/**`만 · taste 스킬 준수 · **병렬 배치 B8·B9가 컴포저/셸을 작업 중** — 매니페스트·아이콘·SW 중심으로 작업하고 셸 CSS 충돌 최소화(충돌 시 B8/B9 우선).

## 1. 할 일
- **Web App Manifest**: name/short_name(oort)·display `standalone`·theme_color/background_color(다크 기조 토큰과 정합)·start_url·scope·아이콘 세트(192/512 + maskable). 아이콘은 기존 `public/oort-mark.svg`/apple-touch-icon에서 파생(신규 생성 금지 — B4.4가 정한 마크 유지).
- **iOS 대응**: `apple-mobile-web-app-capable`·status bar style·`apple-touch-icon` 확인(이미 있으면 정합만).
- **서비스 워커(최소)**: 앱 셸 캐시로 콜드 스타트 단축 + **오프라인 시 정직한 화면**(캐시된 셸 + "연결 없음" — 낡은 메시지를 최신인 척 보여주지 말 것. 데이터 캐싱은 하지 않는다). 업데이트 시 즉시 활성화(stale 셸 고착 금지) + 새 버전 알림 후 새로고침 경로.
- **설치 유도**: 폰 브라우저 첫 방문 시 1회, 절제된 안내(iOS는 공유→홈 화면 추가 안내 — beforeinstallprompt 미지원). 무시/닫기 기억.
- **standalone 모드 대응**: 홈에서 열었을 때 safe-area·상단 status bar 영역 처리(B9와 정합).

## 2. 하지 말 것
푸시 알림(ADR-0120은 NSE 경로 = RN 몫)·데이터 오프라인 동기화·새 아이콘 디자인·RN 관련 작업.
