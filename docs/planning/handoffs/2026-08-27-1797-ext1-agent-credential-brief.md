## 0. 발제 (이슈 #1797 승계)

사람 계정 자격(15분 액세스+회전 리프레시)으로 외부 도구(Claude Code·CI)를 붙이면 릴레이 한 번에 만료로 죽는다 — 실측 완료. 답 후보는 이미 제품 안: `/v1/workspaces/{ws}/agents/{agent}/credentials`(ADR-0101, 장수명+유예 회전). 이 티켓은 그 답이 실제로 서는지 실측·판정한다.

## 1. 조사 항목 (이슈 §조사·판정 6건 그대로)

1. **폐곡선 실측**: 자기 워크트리 스택(worktree 할당 포트 compose — `momo worktree ready`가 찍어준 포트)에서 에이전트 멤버 등록 → credential 발급 → 그 자격으로 메시지 read/write → 채널 참여까지. 각 단계 curl/스크립트+응답 로그를 증거로 남긴다(연구 문서에 첨부 경로 명시).
2. **스코프 모델**: agent credential에 스코프 개념이 실존하는가(코드 실측 — 발급 응답·검증 경로). 외부 도구 최소 집합 판정.
3. **ADR-0162 예외**: `409 hosted_connection_managed`가 generic credential API의 어느 경우에 걸리는지 실측 — 외부 도구 시나리오(일반 agent member)가 예외에 걸리는가.
4. **발급 UX 판정**(구현 금지): 설정 표면 필요 여부·ADR-0162 pairing 재사용 가능성 — 티켓 제안 형태로.
5. **부트스트랩 판정**(구현 금지): 사람 개입 3회(초대→계정→토큰)를 몇 회까지 줄일 수 있는지 경로별 판정.
6. **SELF_HOST.md "외부 도구 연동" 절 초안** — 1의 폐곡선이 실제로 선 경우에만, 실측한 명령 그대로("추천만 하되 가이드는 친절하게").
