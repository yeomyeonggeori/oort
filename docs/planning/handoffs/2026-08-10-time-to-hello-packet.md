## 임무

1. **정본 퀵스타트 1문서**: `docs/SELF_HOST.md` 신설(또는 `infra/rust/README.md` §퀵스타트 승격 — 어느 쪽이 한 문서로 서는지 판단해 근거 보고). 내용: 전제(Docker) → clone → env 준비(필수 키만·생성 명령 동봉·`MOMO_INITIAL_OWNER_*` 포함) → `docker compose up -d`(오버레이 조합 — 로컬은 caddy 오버레이 **제외**가 기본: #1239 ACME 위험, `MOMO_RUST_API_PORT` 직접 접속+웹은 이미지 스테이징 볼륨 서빙 경로 중 실작동 조합을 실측해 확정) → 로그인. TLS/도메인이 있는 프로덕션 절은 별절로 분리(caddy 오버레이+#1239 경고 링크).
2. **재실측이 수용기준**: 깨끗한 클론(레포 체크아웃 밖 임시 경로)에서 문서를 **그대로** 밟아 메시지 1왕복까지 — C의 `smoke.mjs` 방식 재사용 가능(C 보고서에 경로). 소요·명령 수·임기응변 수를 기록. **임기응변이 1개라도 나오면 문서나 코드를 고쳐 0으로 만든 뒤 다시 밟는다**(그 수리가 이 티켓의 본체다).
3. README(main)의 Getting started 갱신은 **하지 마라** — 경로 증명 후 오케스트레이터 몫. 대신 README에 넣을 3~5줄 제안을 보고에 포함.
4. `docs/RUN.md` 전면 재작성이 이 문서로 흡수 가능하면 RUN.md 상단 배너를 새 정본으로 재조준(내용 재작성은 범위 밖).
