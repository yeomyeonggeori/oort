# 일반 사용자 대응 계획 — 온보딩·보안 서사·커넥터 (2026-07-27)

성재 발제 3건("브라우저 왕복 가입", "보안은 어떻게 답하나", "코덱스 같은 커넥터 UI")을
코드 조사로 확인하고 실행 단위로 나눈 문서. 조사는 오케스트레이터가 file:line으로 재현했다.

## 0. 한 줄 판정

**세 질문은 같은 결정을 가리킨다** — 셀프호스팅 도구에서 **일반 유저 제품**으로 무게중심을
옮기느냐. ADR-0121 D6-A가 "기본 공개 서버 비내장"을, D5-A가 oort Cloud를 **범위 밖**으로
못박았기 때문에, 그 이동은 **새 ADR이 필요한 경계 변경**이다.

따라서 **결정이 필요 없는 것부터 즉시 착수**하고, ADR 선행 항목은 분리했다.

## 2. ADR 선행 (착수 금지)

### ADR-0138 (신규 기안 필요) — 일반 유저 온보딩 경계 / oort Cloud

**무엇을 결정하나**: 초대 없는 self-signup을 열 것인가, 그렇다면 어디에서(브라우저) 하고
앱은 어떻게 결과를 돌려받는가.

**조사로 확인된 현재 상태**:
- 브라우저 왕복의 **후반부는 이미 배선돼 있다** — `momo://` 스킴 OS 등록(`tauri.conf.json:27-32`),
  전달(`lib.rs:100-122`), **콜드스타트 버퍼**(`deeplink.rs:124-156` — 앱이 꺼져 있어도 유실 없음),
  URL에서 비밀값 즉시 제거(`deepLink.ts:120-137`).
- **전반부도 절반 있다** — 앱→시스템 브라우저 열기(`opener.rs:70-111`)가 **https만 허용**하도록
  좁혀져 있어 인증 URL에 오히려 적합. 단 지금은 아티팩트 카드에서만 쓰이고 인증 목적 호출 0건.
- **없는 것**: https 유니버설 링크(`apple-app-site-association`·`assetlinks.json` 0건) ·
  인증 플로우(device code/PKCE 없음, `AuthRoutes`는 login/refresh/logout/realtime-token 4개가 전부) ·
  콜백 토큰 규약(`momo://join`은 `server`+`code`만 받고 나머지 무시) ·
  **초대 없는 계정 생성 경로 자체**(`JoinRoutes.swift:19-30`이 유일 생성 경로, 초대 코드 필수).
- **ADR-0121이 탈출구를 예약해뒀다**: D2-A "Dawn이 단축 도메인만 소유, 검증·가입은 대상 서버에서" —
  유니버설 링크의 도메인 검증 문제를 우회하는 설계가 문서상 결정돼 있고 구현(S-4)만 미발행.
  `services/LinkShort`가 이미 `/i/{code}` → 대상 서버 302로 돌고 있다.

**핵심 질문**: 셀프호스팅 우선을 유지한 채 **초대받은 사람의 합류 경험만** 개선할 것인가,
아니면 **oort Cloud(SaaS 인스턴스)** 를 열 것인가. 후자는 ADR-0121 D5-A/D6-A 개정이다.

### ADR-0113 증보 (필요 시) — 3자 OAuth 커넥터

스크린샷의 Canva형 "**사용자가 자기 계정을 연결**"은 현재 모델과 다르다. oort는
"관리자 설치 → 멤버 self-grant"이고, **ADR-0113 D1-A가 OAuth 토큰 취득을 에이전트 호스트로
밀어놨다**(oort 서버는 카탈로그·정책·grant 기록·감사만). 스키마 주석도 토큰 보관을 명시 금지
(`013_plugin_registry.sql:26-27`).

→ 3자 계정 연결을 진짜로 하려면 **ADR-0113 재개정이 선행**. 반대로 MOMO-637은 현재 모델 그대로
가므로 ADR 불요.

   제3자 제공(LLM 제공자)·보유기간·책임자가 **전부 빈칸**이다. **이 상태로 링크를 보내면 역효과**다.

## 4. 조사에서 나온 사실 (근거)

### 보안 — 구현은 강한데 말할 자료가 없다
- 강한 것: RLS **FORCE** + 부트가드(`DatabaseSecurityPosture.swift:20-31`, 조건 불충족 시 **부팅 거부**) ·
  단일 쓰기경로 · ADR-0004 자격증명 비유입(검증 스크립트 fail-fast) · 감사 로그 + admin 조회 REST ·
  첨부 capability URL 직송(바이트가 서버 미경유) + 채널 멤버십 게이트 + 15분 만료 + 저장소 메타 대조 ·
  Drive는 SA `drive.readonly` + driveId 강제·재검증, 자격증명 DB 미저장 · 푸시 id-only.
- 없는 것: **한국어 문안 0건** · 랜딩 사이트 없음 · 위협모델 문서 없음 ·
  **첨부 바이러스 검사 없음**(MIME sniffing 검증도 없음) · 3자 감사/인증 없음 ·
  브라우저 refresh token localStorage · Tauri CSP 미설정 · 구 알파 채널 미서명.

### 커넥터 — 서버는 완비, 웹 화면이 유실
- 서버: 라우트 6종 실동 + RLS FORCE 4테이블 + 공식 시드 4종. 상세 API가 **manifest 통째**를 주므로
  동의 모달에 바인딩할 필드(publisher.verified·license·provenance·tools[].scopes/risk·egressDomains)가
  **이미 다 온다**.
- 웹: plugin UI **0건**. 구 SwiftUI 734줄 마켓플레이스가 은퇴 때 포팅되지 않았고 Tauri 마이그레이션
  계획에도 없었다. **기능 유실**이다.
- 동의 모달은 mac에도 없었다(1클릭 즉시 grant). scope 한국어 변환 로직만 이식 가능
  (`PluginMarketplaceView.swift:626-640`).
- UX 스펙 부재: ux-bible·R-1 웹 스펙에 플러그인 장이 없다. 2026-07-17 핸드오프가
  "카탈로그 UI는 UX 트랙 몫"으로 남겨둔 것이 아직 안 채워졌다.
