# 워커 실행 어댑터

워커를 띄우거나 실행 장애를 복구할 때만 읽는다. 모델과 병렬 판단은 [PIPELINE](PIPELINE.md), 구현 계약은 [AGENTS](../../AGENTS.md)에 있다. 하네스별로 새로운 작업 정본을 만들지 않는다.

| 환경 | 실행 경로 |
|---|---|
| Claude Code | Agent 도구로 서브에이전트를 발사한다. 모델은 생략해 부모 모델을 상속하고, 구현은 `general-purpose`, 읽기 전용 조사는 `Explore`, UI 검수는 `design-review`를 쓴다. 이름은 붙이지 않는다(이름 붙인 팀메이트는 지시 전달이 끊긴 전례가 있다). 긴 작업은 백그라운드로 두고 완료 알림으로 수거한다 |
| Codex | 요청한 모델을 지원하는 native subagent가 있으면 사용. 실제 모델·세션 ID를 확인 |
| 은퇴 | Grok(grok-fleet 스크립트·Cursor CLI grok) — 2026-09-23 |

입력은 이슈·필요한 패킷·기준 브랜치·허용 파일·검증·인계 지점이면 충분하다. 미션 파일은 `claudedocs/resume-<날짜>/mission-*.md`에 두고 프롬프트는 그 경로를 가리킨다. 동시에 작업할 때 파일 소유권을 분리한다.

## 관측과 복구
- 발사한 에이전트 ID, 워크트리, 변경 커밋, 다음 행동을 공용 체크포인트에 남긴다.
- 세션 한도(HTTP 429)나 도구 오류로 끊긴 워커는 새로 띄우지 말고 같은 에이전트에 SendMessage로 「남은 단계부터 이어서」를 보낸다. 워크트리의 미커밋 변경을 먼저 확인한다.
- 완료 알림의 요약만 믿지 않는다. 실제 커밋·PR·검증 원문을 확인한다.
- 모델·제공자의 권한/콘텐츠 거부는 사유를 기록하고 해당 동작을 중단하며 다른 경로로 우회하지 않는다.
- 자격증명·전체 로그는 공용 문서에 복사하지 않는다.

출력은 한 일 / 커밋·파일 / 검증 / PR / 남은 것·이탈로 충분하다. 구체적인 버그가 있을 때만 실패 재현·회귀 증거를 요구한다.
