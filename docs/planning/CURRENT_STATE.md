## 재개
1. `scripts/planning_context.sh`로 복원한다. main·engine·uxui 정렬을 확인한다.
2. 미션·승격 헬퍼(`promote-lib.sh`)·착륙 대기열·인계 노트는 로컬 `claudedocs/resume-2026-09-23/`에 있다. 계약은 이슈와 레포 문서가 정본이다.
3. 서버 배포·owner 기기 증거 빌드는 상시 사전 허가(2026-10-14). 팀원이 받는 TestFlight·DMG는 빌드마다 owner 승인. 발행 워크플로의 GitHub `release` 환경 승인은 관문이 둘이다(이미지 빌드·목록 합치기).
4. 워크트리·스크래치 회수는 `~/.local/bin/momo-worktree-reclaim.sh`가 한다. 엔진 워커 `target`·워커 시뮬레이터는 랜딩 직후 회수한다. 시뮬레이터는 실행 중 워커가 복제 원본으로 쓰는지 확인한 뒤 지운다.

이 파일은 현재 상태 하나만 유지한다. 결정은 ADR, 검증 원문은 PR 본문, 세션 이력은 JOURNAL, 실행 중 note는 공용 로컬 폴더에 둔다.
