## 1. 확정 결정 (E1~E10)

| # | 결정 | 내용 |
|---|---|---|
| E1 | **1차 런칭 타겟 = 그록봇 사용 가능 유저 한정** | 셀프호스팅·봇 연동이 이 타겟 안에서 매끄럽게 결합된다는 가설. 성격은 **퍼블릭 오픈 + 타겟 마케팅만 축소** — D1 셀프서브 퍼널은 공개 유지, 메시지·채널만 그록봇 커뮤니티 집중. 배포 통제 아님 |
| E2 | 구독 연동 방침 | **둘 다 지원, 구독 연동이 1순위 UX, BYOK/OpenRouter 폴백**. 단 v1은 축소형(E3) |
| E3 | v1 구독 연동 = "그록봇 합류가 곧 구독 연동" | 그록봇 유저는 전원 SuperGrok 구독자 — 그록봇이 에이전트 멤버로 합류하면 추론은 그록봇 쪽에서 발생, oort는 provider 자격증명 비유입(ADR-0004 정합). Claude/ChatGPT 구독 OAuth 직결·OpenRouter BYOK(내장 AI 축)는 리서치 후 v1.5+ |
| E4 | 에이전트 감지 = 북극성, v1 스코프는 그록봇 단일 | oort 데스크탑 앱이 로컬 Grok Bot.app 설치 감지 → "그록봇을 팀에 초대할까요?" 원클릭 → 페어링 위저드(#1360) 자동 채움. 커버: 비-PLN 수동 설치 유저 + **VM 리셋/Update 후 재페어링**(복구 UX 겸함). 감지 레지스트리는 확장 가능 구조(Claude Code·Codex는 v1.5+) |
| E5 | 감지 품질 바 | **best-effort + 매끄러운 수동 폴백**(위저드 안내). 감지 성공률 수치 게이트 없음 |
| E6 | 온보딩 완료 판정 = **그록봇과 첫 왕복** | 첫 멘션→그록봇 응답 도착 순간. 게이트 QA 기준: 미도착=불합격·무음 실패=불합격(4-상태 의무)·에이전트 뱃지 누락=불합격(agent=1급 member 정체성). 응답 시간 상한은 게이트 아닌 측정 항목(bench p50/p95) |
| E7 | Slack 마이그레이션 = 리서치 지금, 구현은 게이트 밖 기본 | export zip vs API 비교표+선택지별 티켓 초안이 리서치 완료 판정. 소형이면 게이트 승격 상신. 스키마 경계 시 ADR 선행 |
| E8 | 타임라인 | 3축 리서치는 PLN 시리즈와 **병렬**, 완료 기한 = "PLN E2E 수용 런 전". 감지·등록 티켓은 리서치 완료 즉시 PLN 티켓들과 같은 파도 편성 |
| E9 | aside 리서치 깊이 경계 | 공개 표면 전부 + 자기 계정/자기 트래픽 관찰까지. **private API 리버스·재현 구현·스크래핑 금지** |
| E10 | 리서치 산출물 계약 | `docs/planning/research/` 정본 노트 + oort 매핑 표(패턴→설계→티켓 후보). 완료 판정 = 각 축 티켓 초안 작성 가능 구체성 |

## 2. 1차 런칭 게이트 구성 (E1~E6 종합)

**게이트 = PLN E2E(D7·D8) + 그록봇 감지·원클릭 등록(E4·E5) + 첫 왕복 온보딩(E6)**. Slack 마이그레이션·다중 provider 구독 연동은 게이트 밖 순차(승격은 상신).

온보딩 흐름(aside 대응):
```
[aside]  다운로드 → Chrome/Google에서 가져오기 → AI 구독 연결 → 첫 태스크
[oort]   데스크탑 다운로드 → (Slack에서 가져오기: v1.5+) → 그록봇 감지·초대(=구독 연동) → 첫 멘션 왕복 ✓완료
```
