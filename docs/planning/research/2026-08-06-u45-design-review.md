# Design Review — U4-5 배치 (웹 #1098 + 폰 #1100) @ 52632a44 — Verdict: PASS(B0·H1·M3·N4)

> 전문은 오케스트레이션 기록. 실측 요지: 착지 틴트 픽셀=warnSurface 정확 일치·기준선 +0.33pt 확인·slopTo 산수 실증·접기/배지 게이트 전항 PASS·삭제 접기 문 규칙 캡처 확인.

## High
- **H-1 (폰)**: 접힌 묘비를 가리키는 인용 점프가 거짓 안내 — deletedFold가 롤업·반응 문은 지키나 **인용 문 누락**: 삭제 원본 인용 블록은 점프 가능한데 원본이 연속 묘비로 접히면 findIndex 실패 → 「위로 올려 더 불러오세요」(이미 로드돼 접혀 있을 뿐인데 틀린 지시). 방향: factsFor에 「인용 대상인가」 3번째 사실 주입 or 점프 미스 시 접힌 머리 행 착지.

## Medium
- M-1 (웹): 터치 웹에서 접기 토글 ~18px — 같은 배치가 폰 44pt를 도출식 강제하면서 터치 웹은 WCAG 2.5.8(24px) 미달. 후속.
- M-2 (폰): 터치된 파일의 기존 em-dash 2건(MessageRow.tsx:610·715 — base 선재 확인). 스윕 필요.
- M-3 (웹): 「새 메시지 N개 보기」가 내 확정 전송도 센다(countNewerThan이 저자 미확인) — 그 낱말은 안읽음 구분선에서 남의 메시지를 뜻함.

## Nit
- N-1 바닥 펼침 직후 점프 필 등장 잡음 · N-2 details 네이티브 토글 시 로빙 한 렌더 지연 · N-3 폰 onAccent가 danger 위에도(라이트 모드 때 이름 거짓말) · N-4 착지 틴트 무한 지속(드래그 전까지 — 의도 수용, 비용 기록)
