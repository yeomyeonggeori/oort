# 셀프호스트 URL 안정성 — 우로보로스 인터뷰 확정본 (RA-6 후속)

> 2026-08-25 성재×Fable 5라운드 인터뷰(interview_20260825_042044, 모호도 0.17 수렴). 발단: RA-6 성재 결정 질문 2건 → "셀프호스팅 사용자 관점에서 안정적 서버 URL 발급·사용" 제품 범위 확정.

## ① 확정 사항

**타겟**: 1차=제로터치 셀프호스터(운영 지식 0, "oort 깔아줘" 한마디 — docker 설치도 그록봇 대행) · 2차=숙련자(CF/AWS 자기 인프라+자기 도메인, URL 문제 원천 부재 — 문서 매트릭스만).

**3-Tier 구조 (성재: "B 기본(먼저), A 폴백 선택")**

| Tier | 내용 | 의존성 |
|---|---|---|
| **B 기본** | 그록봇이 서드파티 터널(현행 Tailscale Funnel) 자동 프로비저닝. **터널 정체성(state dir)을 영속 공간에 보존 → 재프로비저닝에도 같은 URL** | oort 중앙 의존 0 |
| **A (개정 — 폴백이 아니라 무계정 tier)** | oort 직영 고정 URL. **RA-7 정정**: ①무계정+고정URL을 동시에 주는 서드파티는 **존재하지 않는다**(이름 소유권에 신원이 필요한 구조적 이유) → A는 "편의 폴백"이 아니라 **계정을 만들지 않으려는 사용자의 유일한 구현**이다 ②**CNAME으로는 불가**(Funnel 커스텀 도메인 미지원, GH #16478) → **TLS 종단 프록시**(oort가 릴레이를 자체 운영)여야 한다 | oort 도메인+릴레이 운영 |
| 숙련자 | 자기 도메인=자연 고정 URL. 터널 선택 매트릭스 문서 | 0 |

> **2026-08-26 RA-7 반영**: B트랙 성립 확인(state 영속 → 같은 URL·인증서 재발급 0회). 단 **"계정 0개"는 달성 불가** — 사용자 자기 tailnet이 유일한 적법 경로이고(oort tailnet 수용은 ToS 소지+ACL로 전 고객 서버 접근권), 대가는 **터미널 명령 0회 + 브라우저 클릭 4~5회**다. 성공 기준의 "사람 터미널 명령 0회"는 유지되고 "계정 0개"는 애초에 세운 적 없으나, 제로터치 문면이 그렇게 읽히지 않도록 여기 적어 둔다. 진짜 blocker는 Funnel WS 1001 드롭(#18827) — soak 미실측.

**제품 불변식**: ①"URL은 바뀌지 않는다"(성재 직관 "IP는 달라도 고정 URL 가능하지 않을까"가 정답 방향 — IP가 아니라 정체성 상실만이 URL을 바꾼다, B 트랙 핵심=정체성 영속) ②중앙 디스커버리 v1 부재(의존성 없음 원칙) ③조용한 실패 금지(5분 초과 다운타임 반복 시 그록봇이 사용자에 보고) ④셀프호스팅은 oort 중앙과 완전 독립 동작 가능.

**성공 기준**: 초기 셋업=사람 터미널 명령 0회·브라우저 클릭 2회(claim 비번+앱 로그인)·콜드 VM 15분 내 첫 메시지(근거 #1240 63초 실측) / 재프로비저닝 복구=사용자 행동 0·같은 URL·데이터 무손실·5분 내 자동(durable inbox+도어벨이 수십 초 지연 흡수).

**희귀 URL 상실 폴백**: 그록봇이 새 URL 메시지 통지 + 데스크톱 앱 "새 서버 주소 입력" 안내 흐름을 1급 상태로(재로그인 마찰 축소).

## ② 후속 리서치 질문 (RQ-1~7)

- **RQ-1 [최우선]** Tailscale state 영속화 실측: /workspace 마운트로 리셋 후 같은 Funnel URL 복원+LE 인증서 캐시 영속(34h rate limit 해소) 검증 절차 포함.
- **RQ-2 [B blocker 후보]** Tailscale 계정 요구 vs 제로터치: 그록봇 대리 계정 생성 약관 허용? pre-auth key로 무로그인 노드 등록? 무계정 대안 터널(고정 URL 필수 평가).
- **RQ-3** CF-origin 트래픽 판정(named tunnel에서 1015 재현 여부 실측) — RA-6 미확증분.
- **RQ-4** A-트랙 별칭 기술 선택지: CNAME vs 리다이렉트 vs Workers 프록시(WS 호환·TLS 종단·지연), 와일드카드 SSL 운영 비용, 프로바이더 교체 시 재지정 API.
- **RQ-5** 재바인딩 자동화 갱신 대상 전수(from-code): 앱 서버주소·ADR-0110 WS URL·그록봇 루틴 지시문·도어벨 webhook — 서버 자동 가능분과 외부 재등록 불가피분의 경계.
- **RQ-6** Funnel 무료 지속 확정 방법(공식 문의 vs Premium 선수용 경제성) + 유료화 시 대체 프로바이더.
- **RQ-7** 그록봇 /workspace 영속성 보장 범위: "resettable" 트리거의 실체 — 전부 /workspace면 리셋=URL 불변식 붕괴, 외부 백업 전략 필요 여부.
