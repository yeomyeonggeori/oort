> 성재 요청: buzz 코드 탐색 김에 "가져오면 좋을" UI 격차 후보화. 탐색 에이전트가 양쪽 실코드 대조(파일 경로 검증 완료, 추측 0). 이미 처리된 BZ-1~4·6a·ADR-0174 영역 제외. **발급 전 후보 — 성재 선택 대기.**

## 비권장 (조사 후 제외, 사유 기록)
- **Pulse**(채널 밖 마이크로블로그) — UI 격차가 아니라 제품 방향 결정. 단 "에이전트 활동 피드 묶기" 아이디어만 activity/에 이식 여지.
- **Local archive** — buzz의 nostr 릴레이 휘발성 제약 고유물.
- **Channel templates** — 채널 생성 빈도 낮은 현 단계 효용 부족.
- **스레드 Split/Focus 선택** — 폭 리사이즈(A10)만 취사.
- **GIF picker** — 서드파티 계약+서버 프록시 비용 대비 내부 도구 효용 중간.
