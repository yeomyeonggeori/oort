# BZ-6 온보딩 경험 설계 v2 (#1869) — buzz 실물 리서치 반영

> 2026-08-29 Fable. v1 → **v2: buzz 온보딩 실코드 분석**(`2026-08-29-buzz-onboarding-research.md`) **반영 개정**. 성재 컨펌 후 구현 티켓 분할.

## 1. 설계 원칙 (buzz에서 확증된 것)
- 화려함은 에셋이 아니라 **연출**에서 온다: buzz의 비트맵 에셋은 로고 1장(12KB)뿐 — 브랜드 컬러 필드+도트 격자+코드 마스코트 산포+정교한 전환 이징이 전부.
- 온보딩의 절정은 화면이 아니라 **첫 5분의 실사용**: 스타터 에이전트가 웰컴 채널에서 실제로 말을 건다(투어 카드 아님).
- "지금은 건너뛰기" 상시 제공, 저장 실패에도 전진 가능(복구 설계), 랜딩 화면만 진행바 없음.

## 2. 스텝 설계 (oort 5스텝 → buzz 문법 대응)

**S0 랜딩 (진행바 없음, 중앙 정렬) — "오르트 구름을 지나 들어온다" (2026-08-29 성재 지시: Dawn 면 제거, 오르트 중심)**
- 배경: **딥 스페이스 단일 룩 커밋**(다크 잉크 우주 면 — 온보딩 랜딩은 두 스킴을 두지 않는 브랜드 순간, 디자인 시스템의 단일-룩 예외 절차로 배경·색 명시). 미세 별 격자(성긴 radial-gradient 점, buzz 도트 격자의 우주 번역).
- **오르트 구름 산포 필드**: 브랜드 서사 그대로 — 오르트 구름은 태양계를 감싸는 혜성 껍질. 라인아트 혜성·소행성·별 소도형 ~30개가 **화면 가장자리를 감싸는 껍질 배치**(중앙은 비움), 2색(액센트 호박+연한 잉크), 크기 22–36px, 회전 변주. rAF 배회(개체별 비정합 사인파)+**마우스 반발**(반경 180px, easing 0.12)+반짝임 CSS 키프레임(컴포지터). reduced-motion=정지.
- 중앙: **OortMark**(기존 정본 SVG — O 말풍선+궤도, currentColor) 대형 스케일 + 궤도 stroke 드로잉→미세 회전 모션. 마스코트 본체 변형 없음(소도형은 주변 요소 — 정본 "변주는 성재와 함께" 저촉 없음).
- 선택 2택: 「우리 팀 서버로 접속」 / 「초대 링크로 참여」.
- 이후 스텝 전환은 다크 우주 → 라이트 카드로 mask-reveal — "구름을 지나 워크스페이스로 들어오는" 진입 서사.

**S1 서버/초대** — 주소 입력(+최근 접속 칩) 또는 초대 코드. buzz의 identity/key 스텝 자리를 우리 계정 모델이 대체(더 짧음).

**S2 계정** — 로그인 또는 join(이름·핸들·비번). 오류 문장형 유지.

**S3 프로필** — 표시 이름·아바타(건너뛰기 상시, 실패에도 전진). ※BZ-4 프로필 편집 서버 표면과 공유.

**S4 웰컴 킥오프 (절정 — buzz D층 이식)**
- 진입 직후 웰컴 채널에서 **김인턴(hermes)이 먼저 말을 건다**: "무엇을 만들고 계세요? 하나 가져오시면 같이 시작해요" 톤의 오프너.
- provider/자격 미구성이면 그 안내조차 김인턴이 채널에서 말함("설정 › AI 연결에서 연결하고 돌아오면 시작해요").
- 멱등 마커로 1회만 게시(buzz opener/closer 마커 동형). 채널·에이전트·허들 소개는 이 대화 안에서 자연스럽게(정적 투어 카드 폐기).

**전환 연출(전 스텝 공통)**: buzz 이식 — effect 5종(fade/line-slide/mask-reveal-down·up/none) × 방향. line-slide **650ms cubic-bezier(0.22,1,0.36,1)**, mask-reveal **760ms**, fill-mode backwards(잔류 transform 함정 회피 주석까지 승계). 4단계 카운터.

## 3. 에셋 전략 (v2.1 — 오르트 중심 확정, 2026-08-29 성재 지시)
- **정체성 축 = 오르트 우주 서사**: Dawn 팔레트 면 사용 안 함. 딥 스페이스 필드 + 오르트 구름(혜성 껍질) 산포 + OortMark 중앙 — "오르트 구름을 지나 워크스페이스로 들어온다"는 진입 서사로 통일.
- **코드 모션 단독**: SVG 산포 필드 + CSS 키프레임 + rAF 인터랙션 + CSS 배경. buzz가 이 재료만으로 목표 수준의 화려함을 실증(비트맵 1장·영상 0). 소도형은 워커가 라인아트 문법(단일 스트로크 굵기·currentColor·3D 금지)으로 직접 path 작성.
- **grok imagine 영상·meshy 3D: 불요 확정**(지출 0). grok build 이미지 생성은 시안 대안 탐색이 필요해질 때만 보조로.
- 소도형 시안은 별도 사전 확인 없이 구현 진행(성재 2026-08-29 위임) — 랜딩 후 실화면으로 검수.
