## 즉시 답변형 (질문 — 작업 아님)

### Q2. 로컬 에이전트 게이트웨이 연동 / ACP 채택 여부
- **로컬 LLM 게이트웨이(localhost:포트) 연동 = 이미 됨.** `CreateAgentDialog`의 "게이트웨이 주소" + `AiLinkSection` base URL, `AGENT_PROVIDER_ALLOW_LOCAL_LOOPBACK=1` opt-in(ADR-0004). 로컬 **코딩 에이전트**는 주소가 아니라 `momo-workd` 데몬 페어링. 원격 self-onboarding(A2A Agent Card 주소)은 설계·**Swift 구현은 있으나 현행 Rust 미이식**(감사 §3).
- **ACP(Zed Agent Client Protocol) = 로컬 코딩 에이전트 계층의 공식 채택·구현**(ADR-0130 Accepted 2026-07-21·MOMO-531·`verify_acp_host.sh`). 단 전 계층 단일이 아니라 다층: LLM 멤버=OpenAI SSE(Hermes)·코딩 에이전트=ACP(∪Codex JSON-RPC)·원격=A2A Card·MCP=툴 레이어. IBM "Agent Communication Protocol"은 미채택(2025-08 A2A로 소멸).

### 디자인 시스템 구현 수준 = **5단계 중 4단계**
- (a)문서·(b)토큰+프리미티브 초과, **(c)다층 게이트로 기계 강제까지 도달.** 셸 프리플라이트 10분류·단위 스위트·Playwright 게이트 26개·**크로스클라 바이트 대조**(웹 tokens.css를 폰 테스트가 읽어 대조 — 업계에 없는 자산·axe 커버 0%). 5단계(렌더 시각·4상태·한국어 조판·비텍스트 대비 자동검증)는 "무엇이 안 재지는지"까지 문서화만 하고 미구현.
- 축별: **색=완전**(유일하게 완전히 흐름) · 간격·반경=높음 · 타이포=중상 · **그림자·모션=최저**(RN 구조적 분기). 스테일 1건: README §3.3이 #1210 랜딩분을 아직 ❌로 표기(문서가 코드보다 반 걸음 뒤 — 정정 필요).

## 성격별 처리 계획

### A. 즉시 프론트 (ADR 불요 — 성재 방향만)
- **5-공간**: 워크스페이스 레일 폭을 32px에서 널널하게(디스코드 48~72px급)·타일 히트영역·현재/호버 여백 확대. 이미지 업로드는 4b.
- **6-레이아웃**: 멤버·에이전트 탭 방향(전체폭 통일 / 중앙정렬 / 넓은 캡 중 택1) — 채팅·인박스·활동은 이미 전체폭.
- **4-알림규칙**: 삭제 시 섹션 4곳+인박스 링크(이미 목적지 깨짐)+캡처 참조 정리. 실기능이면 서버 REST 신설(대형).
- **1-업데이트 dev 가드**: 로컬/dev 빌드가 자동 업데이트 체크를 건너뛰게(`store.ts`/`updater.rs` dev 가드) — 재발행 없이도 로컬 롤백 근절.

### B. ADR 승인 후 (경계 변경)
- **3-6b**: presence 모델(ADR-0160 — online/away/dnd·set/read API·Centrifugo 프레임) → 프로필에 상태칩+변경 UI. **새 쓰기 이음매 0**(ADR-0149 휘발 경로 재사용).
- **5-4b**: 워크스페이스 아바타 이미지 업로드(ADR-0161 — ADR-0151 Drive 계약 재사용)+멀티 워크스페이스 스택.

### C. 성재 맥 필요 (오케스트레이터 불가)
- **1-재발행**: 최신 매니페스트 발행 = 성재 맥에서 `publish_next_build.sh`(minisign 키·Developer ID·notarytool 프로파일). 이게 근본이나 dev 가드(A)로도 검수 롤백은 막힘.
