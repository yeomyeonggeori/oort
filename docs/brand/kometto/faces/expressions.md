# 코메토 플랫 표정 6종 — 규격 시트 (#2806, ADR-0193 D9·D11)

코메토 표정 6종의 정본이다. owner가 고른 **K6 플랫**(`../K6-flat-dark.png`)을 형태·비례·색 그대로 두고, **검은 얼굴 창 안의 눈만** 바꿨다. 물방울 후드, 무광 흰 점 눈(빛나지 않는 크림 단색), 말풍선 림은 원본 픽셀 그대로다. 에셋은 배지 원판을 걷어 낸 **투명 컷**이다. 3D 클레이 표정 시트(`claudedocs/brand-2.0/round3/K6-expressions.png`)는 표정 모양의 참고로만 썼다.

**M2 결정(planner, 위임 범위, 2026-09-26): (c) 흉상에서 원판만 걷어 낸 투명 컷.** 인용: 「owner가 고른 K6 픽셀을 그대로 쓰는 원칙(#2732 전례)을 지키면서, 어떤 바탕에서도 보이게 만드는 유일한 안이다. 전신을 새로 그리는 (a)는 owner 선택이 필요한 새 정본이라 이번에 하지 않는다. 몸 아래가 원호로 잘리는 것은 수용한다.」 전신 플랫 컷은 owner가 새 정본을 고를 때 다시 연다.

## 2. 표정 → 상태 (ADR-0193 D11)

상태와 표정은 1:1이다. **표정만으로 상태를 전하지 않는다.** 코메토의 해요체 한 문장이 항상 함께 간다.

| id | 표정 | 쓰는 상태(D11) | 눈 모양 | 참고한 3D 시트 칸 |
|---|---|---|---|---|
| `idle` | 대기 | 질문을 기다림 | 세로 타원 두 개(원본 그대로) | 윗줄 왼쪽 |
| `thinking` | 생각 | 감지·확인·연결 중 | 오른쪽 위를 올려다보는 작은 타원 | 아랫줄 가운데 |
| `happy` | 기쁨 | 완료·감지 성공 | 위로 볼록한 웃는 아치 ^ ^ | 윗줄 오른쪽 |
| `flustered` | 당황 | 오류·오프라인 | 크게 뜬 링 눈 + 창 안 땀방울 | 아랫줄 왼쪽(점 눈은 72px에서 사라져 링으로 키웠다) |
| `working` | 작업 중 | 에이전트가 준비 중 | 가로 일자 눈 — — | 윗줄 가운데 |

3D 시트의 창 밖 장식(생각의 손·말줄임 점, 작업 중의 방울 진동선, 기쁨의 꼬리 흔들기, 졸림의 웅크린 자세)은 가져오지 않았다. 코메토는 제자리에서 표정만 바꾼다(D11, 120ms 크로스페이드). 흔들기는 한 장짜리 래스터라 몸 전체를 돌린다. 꼬리만 돌리려면 꼬리 층을 나눈 자산이 필요하다(범위 밖).

## 4. 배경과 투명 컷

| 배경 | 확인 |
|---|---|
| 새벽하늘 `canvas` 라이트 `#F7EADB → #EFEDEA → #E2E9F3` | `sheets/sizes-light.png`, `sheets/hero.png` |
| 새벽하늘 `canvas` 다크 `#231D1B → #171A20 → #0F141C` | `sheets/sizes-dark.png`, `sheets/hero.png` |
| 투명 | `sheets/sizes-transparent.png`(체커보드) |

투명 컷을 만드는 법(`cutInPage`, 새로 그리지 않는다):

1. **키잉.** 네 모서리에서 flood fill한다. 바깥 바탕(`#141418` 근처)과 남색 원판(`#222840` 근처)을 잇는 색 선분까지의 거리가 10 이하인 픽셀을 걷는다. 두 색 사이의 안티앨리어싱도 함께 걷혀 남색 테가 남지 않는다. 후드 끝과 방울 사이의 남색도 걷혀 실루엣이 원본 그대로 드러난다.
2. **가장자리 매팅.** 캐릭터 가장자리 2px 띠만 알파를 매긴다. 가장 가까운 걷힌 픽셀을 바탕, 가장 가까운 안쪽 픽셀을 전경으로 보고 투영한 비율이다. 그다음 바탕색을 걷어 낸다. 크림 림이 라이트 바닥에서 남색 테 없이 선다.
3. **원호 자름 페이드.** 몸통과 혜성 꼬리는 원본에서 배지 원에 잘려 있다. 자른 경계에서 안쪽으로 크기의 10%(웹 57.6px, 히어로 280px에서 28px) 동안 알파를 smoothstep으로 0까지 내린다. 자른 경계 = 캐릭터와 맞닿은 걷힌 픽셀 중 바깥 바탕색에 가깝고(원판이 아니고) 배지 원 반지름 ±3.5% 안인 것. 거리는 그 경계에서 잰 챔퍼 거리다.
   - 근거: 원호로 딱 잘린 단면은 투명 바탕에서 「원판이 사라진 배지」로 읽힌다. 몸이 아래로 녹아 사라지면 바닥 위에 선 흉상으로 읽힌다(히어로 캡처).
   - 페이드는 몸 안쪽 색을 바꾸지 않고 알파만 내린다. 다크 바닥에서 페이드 가장자리에 결이 확대하면 보이지만, 표시 크기에서는 보이지 않는다(`sheets/hero.png`).
- 바닥 위에 테두리·그림자를 더하지 않는다. 캐릭터 실루엣(하늘색 후드·크림 림·검은 얼굴)이 라이트·다크 바닥 모두에서 선다.
- 입력 그릇(`surface`) 위에는 두지 않는다. 코메토는 `canvas` 위 머리 자리에 선다(D11).

## 5. 금지

- 표정만으로 상태 전달 — 문장 없이 당황 얼굴만 띄우지 않는다.
- 32px 미만 사용.
- 변형: 늘이기·기울이기·색 바꾸기·외곽선·그림자·광택·3D 질감 추가, 페이드 아래를 잘라 내거나 원판을 다시 까는 것.
- 다른 그래픽과 합성(말풍선·배지·아이콘을 캐릭터 위에 겹치기). 말풍선은 캐릭터 옆에 둔다.
- 표정을 알림처럼 스스로 바꾸기. 코메토는 화면 상태가 바뀔 때만 표정을 바꾼다.

## 6. 만드는 법과 검사

1. **생성.** codex CLI(`codex exec -c model_provider=openai -m gpt-5.6-sol`, 이미지 도구 gpt-image)에 K6-flat-dark와 3D 표정 시트를 참고 이미지로 넣어 「창 안 눈만 바꾼 편집본」을 만든다. 레포 밖 폴더에서 실행했다. 프롬프트는 7절.
2. **크롭.** 생성물은 창 밖이 원본과 미세하게 어긋난다(기쁨 실측: 창 밖 평균 차 2.88, 16 초과 1.58%). 그래서 얼굴 창 부분만 무손실로 잘라 `src/`에 둔다.
3. **합성**(메모리 안). K6 원본의 얼굴 창을 찾아 가장자리 10px 안쪽만, 생성 크롭의 밝기로 원본의 창 검정 ↔ 원본 눈 크림을 섞는다. 창 밖은 원본 픽셀 그대로다.
4. **투명 컷.** 4절. 웹 576, 폰 600.

`node scripts/render-brand-icons.mjs --faces-only --check-only`(또는 전체 `--check-only`)가 검사한다.

- sha256 고정: K6-flat-dark, 생성 크롭 5장
- 합성: 창 밖 = K6 원본(다른 픽셀 0개). 대기가 아닌 표정은 대기와 창 안 1% 이상, 서로 0.5% 이상 다르다
- 에셋(웹·폰 12장): 크기·RGBA·sRGB. 합성물에서 다시 떠낸 것과 평균 차 ≤ 0.5, 16 초과 ≤ 0.1%, 알파 어긋남 ≤ 0.2%. 모서리·원판 자리 알파 0, 얼굴 알파 255
  - 처음엔 파생 임계를 3 / 2%로 두었다. 그랬더니 다른 표정 에셋으로 바꿔 끼워도 통과했다(표정 차이는 576 캔버스의 1–2%). 그래서 조였다
- 대기 웹 에셋의 불투명 픽셀 = S0 배지(`kometto-badge.png`)의 같은 자리(평균 차 ≤ 3)

시트는 `node scripts/kometto-faces-sheet.mjs`가 커밋된 웹 에셋을 그대로 놓고 캡처한다.
