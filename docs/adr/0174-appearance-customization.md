# ADR-0174: 외양 커스터마이제이션 시스템 (Appearance) — 토큰 아키텍처와 게이트 재정의

- 상태: **Proposed** (성재 결재 대기 — D1~D5)
- 날짜: 2026-08-29
- 발의: Fable (BZ-5 #1868 선행 — 성재 2026-08-29 지시 "buzz 세팅 경험 이식, 색·테마 전반 개선")
- 관련: docs/design-system/README.md(정본) · momo-design-taste-web(게이트) · buzz(Apache-2.0) Appearance · #1868 · #1873(멤버 아바타·소개 ADR 후보 동반 상정)

## 배경
성재 검수(2026-08-29): buzz Appearance의 커스터마이제이션(컬러 모드·테마 스타일·액센트 팔레트·글래스·폰트 크기·밀도·링크 프리뷰·스레드 레이아웃 + 라이브 프리뷰)이 제품 경험의 핵심 차별이라는 판정. 현 정본은 **Dawn 팔레트 단일 고정**(tokens.css가 유일 색 출처, 액센트=호박 고정)이고 taste 게이트가 raw color·ai_gradient·pure_bw를 기계 차단한다. 커스터마이제이션 도입은 "팔레트 단일 고정" 경계의 변경이므로 ADR 없이 머지 불가.

## 결정 (제안)

**D1. 토큰 2층 분리 — 의미 토큰은 불변, 값 바인딩만 사용자 설정.**
컴포넌트는 지금처럼 의미 토큰(`--accent`·`--surface`·`--ink`…)만 소비한다. 사용자 설정은 그 **바인딩 층**(테마)만 바꾼다. 게이트(raw color 금지·토큰 경유 강제)는 그대로 유효 — 오히려 커스터마이제이션의 전제가 된다.

**D2. 설정 축 v1 (buzz 대응, 밖은 후속):**
- 컬러 모드: System/Light/Dark (현행 3상태 유지, UI만 신설)
- **액센트 컬러**: 큐레이션 팔레트 N종(기본=호박/Dawn). 임의 색상환 금지 — 각 후보는 라이트·다크 쌍으로 사전 검증(대비 AA·3:1, `--agent` 파랑과의 거리 확보 — 로고·에이전트 정체성 충돌 방지 규칙 유지). 후보 세트는 구현 티켓에서 시안으로 성재 확정.
- 폰트 크기: Smaller/Default/Larger (rem 스케일 바인딩)
- 대화 밀도: Compact/Comfy/Spacious (기존 spacing 토큰 3벌 바인딩)
- 링크 프리뷰 Compact/Rich·스레드 레이아웃 Focus/Split: 기존 기능 여부 조사 후 있는 것만(없는 축은 기능 티켓 분리 — 외양 ADR 범위 밖)
- 라이브 프리뷰 패널(설정 화면 내 실물 미니 대화) 포함
- **글래스(반투명 배경)는 v1 제외** — Tauri 플랫폼별 편차·성능 리스크. 후속 결정.

**D3. 저장·범위**: 개인 설정, 이 기기(localStorage, `momo.web.appearance.v1`) — 서버 동기화는 후속(스키마 접촉이라 별도 ADR). RN(폰)은 동일 의미 토큰 체계로 후속 이식(패리티 티켓 등재).

**D4. 브랜드 정체성 규칙**: 기본 테마=Dawn(호박 액센트)이 항상 첫 값. 온보딩 S0(오르트 랜딩)·브랜드 락업은 커스텀 액센트의 영향권 밖(단일 룩 커밋 유지). "buzz를 훔쳐오는 것"은 **시스템(축·경험)**이지 팔레트가 아니다.

**D5. 게이트 재정의**: raw_color·naked_focus 등 현행 유지. `pure_bw`·`ai_gradient`는 "기본 테마 강제"에서 "**사전 검증된 테마 바인딩 외 금지**"로 재술 — 게이트 스크립트는 토큰 정의 파일(신설 themes 디렉토리)을 허용 목록으로 갖는다. 대비 테스트는 테마 쌍 전수 실행으로 확장(테마 추가=대비 테스트 추가가 기계 강제).

## 귀결
- 구현 페이징: BZ-5a(토큰 바인딩 층+컬러 모드+액센트 N종+대비 전수 테스트) → BZ-5b(폰트·밀도+라이브 프리뷰) → BZ-5c(기능 축 조사분). 각각 design-review.
- 정본 문서(§2 팔레트·§7 미결)와 taste 레퍼런스가 같은 PR에서 개정된다.
- 멤버 아바타·소개(스키마 확장, #1873 등재분)는 이 ADR과 독립 — 별도 상정.
