# ADR-0112: 제품 표면 재정렬 — "비개발자에겐 Slack, 개발자에겐 Codex 앱"

- Status: **Accepted** (2026-07-14, 성재 — Wave A 즉시 착수, B/C는 A 랜딩 후 순차)
- 관련: ux-bible P1~P15(특히 P2·P5·P7·P12), ADR-0111(Work), ADR-0109(unread), MOMO-354..369 랜딩분
- 발단: 성재 실사용 판정 "최악의 경험" (2026-07-14, 스크린샷 6장) — 세부 지적 전체가 이 ADR의 Context다.

## 진단 — 왜 이렇게 됐나 (정직하게)

1. **실행 원장을 기본 표면에 그대로 노출했다.** momo의 차별화(타임라인=원장)를 "모든 메타데이터를 항상 보여주기"로 오역했다. tool_call JSON, CONTEXT/GITHUB/COST 칩, 비용 링이 대화를 침범해 비개발자에겐 공포, 개발자에게도 소음이다. 특히 **데모 모드의 fixture가 개발자용 프로토콜 쇼케이스**라 첫인상이 최악이 된다.
2. **메신저 기본기가 티켓화되지 않았다.** 멤버 디렉터리·DM 시작·채널 헤더(멤버 수/설정)·창 크롬 정합은 redesign 진단(research/13)에 있었지만, UI 웨이브가 셸 미학(위계/토큰)에 치중하며 기본기를 건너뛰었다.
3. **상호작용 레퍼런스가 부재했다.** "Slack 수준"을 밀도·계층으로만 해석했고, Codex 앱이 보여주는 문법 — 호출 시 모델/effort 선택, 승인 정책 프리셋, 하단 드로어 — 을 정본으로 삼지 않았다.
4. **디테일 결함이 리뷰를 통과했다.** 타이틀바 겹침, 안 눌리는 닫기 버튼, 미묘하게 작은 텍스트 — 스냅샷 리뷰가 "구성"은 잡아도 "동작/창 통합"을 못 잡는 구조적 공백.

## North Star (성재 지향점의 성문화)

> **하나의 타임라인, 두 개의 밀도.** 비개발자가 열면 Slack처럼 당연하게 동작하는 메신저이고, 개발자가 토글을 켜면 Codex 앱 수준의 실행 디테일이 드러난다. 에이전트는 1급 동료지만, **동료의 업무 로그가 대화를 침범하지 않는다** — 기본은 "무엇을 했는지 한 줄", 디테일은 한 겹 아래.

## Decision (Proposed)

### D1. 듀얼 모드 — 개발자 모드 토글 (Discord 문법)
- 기본 모드: 에이전트 메시지는 **요약 1줄 + 접힌 카드**. 프로토콜 칩(CONTEXT/GITHUB/DECISION 등)·tool JSON·비용 링·Context Copilot·개발 도구 팝오버 전부 숨김. 승인 카드는 "무엇을 하려는지 + 승인/거부"만.
- 개발자 모드(설정 토글): 현재 밀도 전부 + 비용 표시 별도 토글. 로컬 알파 정보 채우기·로그아웃 상세 공지 같은 운영 정보도 dev 전용.
- 데모 모드 콘텐츠도 기본 모드 문법으로 재큐레이션(첫인상 = 제품, P2).

### D2. Slack 기본기 완성
- **멤버 디렉터리**: 워크스페이스 전체 멤버를 한 화면에서 (검색/역할/에이전트 구분), 여기서 프로필·DM 시작.
- **DM**: 멤버 목록/디렉터리에서 1:1 DM 시작 (서버: `dm` 채널 kind 기존재 — 생성/조회 REST 신설), DM 섹션에 실목록.
- **채널 헤더 재구성**: 멤버 수·주제·채널 설정(이름/주제/멤버 관리) 진입점, 우측 상세 패널과의 정합, **macOS 타이틀바/트래픽라이트 겹침 해소**(툴바 통합).
- 웹훅/플러그인 표면: v0는 **자리 잡기**(채널 설정 내 "연동" 탭 — 인바운드 웹훅 URL 발급까지, ROADMAP §1.2 plugin manifest와 합류 예고).

### D3. Codex급 상호작용
- **호출 옵션**: @에이전트 태그 시 컴포저에서 모델/effort/속도 per-call 오버라이드 (Codex 앱 컴포저 문법). 서버: `agent_run.input.overrides` convention + gateway pass-through(ADR-0004 경계 유지 — 모델 실행은 에이전트 호스트).
- **승인 정책 프리셋**: Codex 앱 문법 3단 — "항상 승인 요청" / "위험할 때만 요청"(기본) / "사용자 지정". per-agent 설정, 승인 카드에 정책 표시. `danger`/전체권한은 서버 fail-closed 불변(ADR-0111 D3).
- **하단 드로어 (⌃`)**: VSCode/Codex 앱처럼 아래에서 올라오는 패널 — Work 실행 transcript·에이전트 활동 라이브 뷰. (raw PTY는 ADR-0111 non-goal 유지 — 드로어는 원장 뷰어다.)

### D4. 첫인상과 온보딩 여정
- **런치/로그인 WOW**: 애니메이션 허용(과감하게, 단 reduceMotion 존중), Codex/Raycast 레퍼런스. 텍스트 스케일 상향, 정보 다이어트(운영 공지·알파 도우미는 dev 모드로).
- **초대→가입→첫 대화 여정**: 운영자가 앱에서 초대 코드 발급 → 초대받은 사람의 가입 → 첫 실행 가이드(채널 안내·에이전트 소개·첫 멘션 유도, Slackbot 패턴 P5). 인앱 가이드 포함.

### D5. 에이전트 운영 가시성 — 대시보드
- 서버: 에이전트별 통계 read projections(호출 수, 총/평균 비용, 평균 토큰, 채널·작업 유형 분포, 최근 실행) REST.
- 앱: 별도 대시보드 표면(사이드바 유틸리티에서 진입). 기본 모드에서도 접근 가능(운영자 가치).

### D6. 디테일 SLA
- "클릭 안 되는 컨트롤, 창 크롬 겹침, 잘린/겹친 텍스트"는 design-review에서 **Blocker 등급**으로 승격(momo-design-taste rubric 갱신). 스냅샷 외에 **실창 상호작용 검증**(버튼 hit-test, 창 리사이즈)을 UI 게이트에 추가.

## Consequences
- (+) 비개발자 온보딩 가능해짐(내부 10인 테스트의 전제), 개발자 가치는 토글 뒤에 보존.
- (+) Codex 앱 문법 차용으로 상호작용 학습 비용 제로화.
- (−) 기본/개발자 두 밀도의 스냅샷·리뷰 표면 2배 — 게이트 시간 증가 수용.
- (−) DM·웹훅 자리·대시보드는 서버 표면 확장 — 단일 쓰기 경로·RLS 불변식 내에서만.
- 보류: 모바일(iOS)은 이 ADR 범위 밖(기존 로드맵 M8 트랙), 스레드/검색(redesign Phase 2 티켓과 합류).
