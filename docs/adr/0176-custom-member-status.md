## 배경
프레즌스는 선언 3종(온라인/자리 비움/방해 금지)뿐 — "무엇을 하고 있는가"(회의 중·외근·휴가)를 말하는 축이 없다. buzz는 이모지+자유 텍스트+프리셋 칩으로 해결하며 기존 프레즌스와 직교.

## 결정 (제안)
1. **스키마**: member(또는 프레즌스 저장 위치 조사 후 그 표면)에 nullable 3필드 — status_emoji(단일 이모지)·status_text(≤80자)·status_expires_at(선택). 마이그레이션, schema_v0 무접촉, RLS 기존 스코프 승계.
2. **API**: 기존 자기 상태 쓰기 경로(setPresenceStatus PUT) 옆 확장 또는 동일 PUT 바디 확장 — 본인만 쓰기, roster projection에 노출, 변경은 기존 프레즌스 브로드캐스트 레일 동승(새 레일 금지). 만료 도달 시 읽기에서 무시(지연 삭제).
3. **클라**: 상태 설정 다이얼로그(이모지 피커 재사용+텍스트+프리셋 칩 5종 한국어: 회의 중/이동 중/병가/휴가/재택 + 지우기), 표시 지점: 사이드바 ProfileCard·명부 행·프로필 다이얼로그·호버(도입 시). 선언 3종과 별도 축(동시 표시).
4. **범위 밖**: 상태 히스토리·자동 상태(캘린더 연동).

## 성재 확정점
1. 필드 3종 스키마 승인 2. 프리셋 칩 5종 한국어 카피 방향
