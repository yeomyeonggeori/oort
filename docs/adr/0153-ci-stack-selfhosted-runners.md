# ADR-0153 — CI 스택: 로컬 게이트 권위 유지 + 셀프호스티드 러너 (클라우드 CI 과금 0)

- Status: **Accepted** (2026-08-06 성재 — "괜찮아 보여. 한 번 더 검토하고 괜찮으면 해당 조합으로 ㄱㄱ" / 재검토 실측 반영)
- Date: 2026-08-06
- 발단: 성재 — "github action말고 jenkins나 argo cd 같은 걸로 대체할 수 없을까? 비용 부담이 좀 있는데."
- 관련: ADR-0107(로컬 게이트=머지 권위 관례) · ADR-0145 증보 2(Swift 퇴역) · #1108(병합 트리 검증 스크립트) · #1116(Tauri CI 신설) · research/2026-08-06-xcode-cloud-transition.md

## Context (실측)

- 최근 한 달 GH Actions 실행 = **Dependabot(무료)뿐**. 빌드 워크플로 3종은 전부 workflow_dispatch 수동("조직 과금 이슈" 주석) — **현재 과금 사실상 0**. 문제는 미래 CI 수요(Tauri 릴리스·이미지 빌드·iOS)의 비용.
- 레포 **PRIVATE**(fork PR 코드 실행 위험 비성립) · 오케스트레이터 gh 권한 ADMIN(러너 토큰 발급 가능) · NCP 서버 2 vCPU/7GB(prod 스택 동거 — 무거운 빌드 경합 위험, Docker 발열 전례).

## Options

- **Jenkins — 기각**: 새 운영 표면(서버·플러그인·보안 패치)이 생기고 macOS 빌드는 어차피 맥 하드웨어 필요 — 핵심 문제(iOS/데스크톱)를 못 풀며 1인+에이전트 팀에 과함.
- **Argo CD — 부적합**: k8s GitOps CD — 우리 배포는 NCP 단일 서버 docker compose(런북 대행 체계가 이미 그 역할).
- **GH Actions 클라우드 러너 — 기각**: private org 분당 과금, macOS 10배 배율.

## Decision

**D1 · CI(테스트·게이트) = 로컬 게이트 권위 유지.** ADR-0107 관례 성문화 — PR마다 클라우드 CI를 돌리지 않는 것 자체가 절감이자 현행 구조(오케스트레이터가 로컬 게이트 실행·머지 판정, #1108 병합 트리 검증 포함). Jenkins류 도입 없음.

**D2 · 산출물 빌드 = GH Actions 워크플로 유지 + 셀프호스티드 러너(과금 0).** 워크플로 파일은 그대로, 러너만 자체 호스팅:
- **macOS 러너(성재 맥)**: Tauri 데스크톱 릴리스(#1116) — 릴리스 때만 온라인(상시 데몬 불요).
- **리눅스 러너(NCP)**: 경량 잡 한정(웹 빌드·이미지 태깅·릴리스 업로드) + nice/cgroup 리소스 제한 — **Rust 풀빌드류 금지**(2코어 prod 경합). 무거운 리눅스 빌드가 필요해지면 그때 별도 빌드 박스 재론.
- **설치 시점 = 첫 자동화 수요 시**(Tauri CI 신설이 유력한 첫 소비자) — 유휴 데몬 선설치 금지.

**D3 · iOS = Xcode Cloud 무료 티어**(월 25 compute시간) — RN 이관 경로(research/2026-08-06-xcode-cloud-transition.md) 그대로. GH macOS 러너 대비 압도적 저비용.

**D4 · CD = 현행 런북 대행 유지**(compose 단일 서버) — 자동화가 필요해지는 시점에 pull 기반 경량 스크립트로 재론(Argo CD 아님).

## Slack·업계 비교

소규모 팀의 표준 절감 경로가 정확히 이것(워크플로 호환성을 유지한 채 러너만 자체 호스팅)이다. Jenkins 전환은 러너 절감과 같은 돈을 아끼면서 CI 정의 이관·운영 부담을 추가로 지불하는 선택이라 열위. Argo CD는 k8s 채택 이후의 도구다.

## Consequences

- (+) 전 수요 과금 0 · 워크플로 자산 보존 · 새 운영 표면 최소(러너 데몬뿐).
- (−) 러너 가용성이 우리 하드웨어에 결합(성재 맥 오프라인이면 macOS 잡 대기) — 릴리스 빈도가 낮아 수용.
- (−) NCP 러너는 prod 동거 — D2의 경량 한정·리소스 제한이 가드. 위반 시(빌드가 prod를 느리게 하면) 즉시 별도 박스 재론.
