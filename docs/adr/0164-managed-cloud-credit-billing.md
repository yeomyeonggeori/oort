# ADR 0164: 관리형 클라우드 크레딧 과금 (원화 크레딧 + list-cost 원장)

> Status: **Accepted** (성재 승인 2026-08-14 — "권장하는 방향으로 진행" 일괄 결재. D6 수치 확정은 구현 티켓 분해 시)
> 근거 정본: `docs/planning/research/2026-08-14-agent-cloud-credit-billing-models.md` (전 수치 출처·조회일 부기)
> 관련: ADR-0004 증보 2(bundled 키 규율) · ADR-0140(T3 수명주기 — pause 동형) · ADR-0156(T3 기질·원가 기반) · ADR-0163(관리형 동봉 호스팅 — 이 과금이 조달하는 표면)

## 배경

셀프호스트는 무료 OSS로 유지한다. 프로덕트 사용자에게는 oort가 인프라(T3 CubeSandbox)와 모델(bundled 키)을 흡수하는 관리형 클라우드를 제공하고, 그 대가를 크레딧으로 받는다. 업계는 "유료 티어 게이트 + 번들 선차감 + 초과분 API 단가 + 인프라비 별도 청구 없음"으로 수렴했고(Cursor·Codex·Grok·Claude Code 동형 실측), 추상 크레딧(ACU류)은 후퇴 중이다(Devin 회귀·v0 전환·Replit 백래시). 원가는 이중이다: NCP 인스턴스 시간(세션-시간당 $0.02~0.08 검산)+모델 토큰.

## 결정 (D1~D7)

### D1. 과금 단위 = 원화 표시 크레딧, 환산은 list-cost
- 크레딧은 **원화 금액과 1:1**(추상 단위 금지 — "1크레딧=1원" 계열). 소진 환산은 **list-cost 원장**: 모델 토큰은 provider 정가 스냅샷, 세션 러닝타임은 시간당 정액(단가는 D6). 환산표는 공개 문서가 정본이며 변경은 사전 고지.

### D2. 단일 원장, 단일 미터
- 토큰비와 인프라비를 **하나의 크레딧 미터로 접는다** — 사용자에게 "VM 요금" 항목을 따로 보이지 않는다(업계 수렴 패턴·성재 앵커). 내부 원장은 두 원가 축을 분리 기록(정산·마진 관측)하되 노출은 단일 잔액.

### D3. running만 과금, paused 무과금
- 세션 러닝타임 과금은 **running 상태에만** 발생한다. paused(턴 사이 하이버네이트 — 인프라 리서치 A1)는 무과금. 이것이 Cursor의 "대화하는 동안만 쓴다" 감각을 보존하는 절충이다.

### D4. 예산 도달 = pause, 종료 아님
- 크레딧 소진/상한 도달 시 세션을 **pause**하고(작업물 보존) 충전 후 재개 가능하게 한다 — ADR-0140 수명주기와 동형, Anthropic Managed Agents 선례. 데이터 손실형 종료 금지.

### D5. HAP 경계 — 차감은 관리형 전용
- 크레딧 차감 = **관리형**(oort가 컴퓨트·모델을 대는 경로) 전용. **연동형(BYOA)·다이얼인형(Agent Port — HAP E1~E7)은 비차감 무료 표면**이다(컴퓨트·모델이 사용자 측에 있으므로). 셀프호스트는 과금 표면 자체가 없다.

### D6. 공정사용 v0 (지출 상한 강제)
- 워크스페이스별 **지출 상한 기본 켜짐**(Grok의 no-spend-cap이 반면교사), 동시 세션 캡, idle 타임아웃→auto-pause. 상한·캡은 사용자가 올릴 수 있되 무한대는 없음.
- 러닝타임 단가·티어 구성(단일 유료+크레딧 팩 vs 승수형)·무료 체험(1회성 크레딧만) 수치는 **본 ADR Accept 시 성재가 확정**(결정 큐 ②③, 리서치 §성재 결정 큐).

### D7. 미결(후속 확인 후 증보)
- 크레딧 롤오버/소멸 — 한국 전자상거래법·선불전자지급수단 규제 법무 확인 선행(결정 큐 ⑦).
- 결제 수단·PG 선정, Cursor Teams Token Rate류 팀 풀링 — v1 범위 밖.

## Consequences

- (+) 성재 앵커("인프라비 없이 플랜 토큰 소진") = 업계 표준과 정렬, 원가 자릿수 검산 성립.
- (+) ADR-0140 pause와 D3/D4가 맞물려 **과금 설계가 인프라 최적화(A1)를 견인** — paused 무과금이 세션 밀도(동시 14→그 이상)를 직접 벌게 한다.
- (−) list-cost 스냅샷 관리 부담(provider 단가 변경 추적) — 환산표 공개 문서가 방어선.
- (−) 운영자 bundled 키가 고가치 시크릿화 — ADR-0004 증보 2 + D6 상한이 안전판.

## 구현 스케치 (Accept 후 티켓 분해)

usage_ledger 확장(러닝타임 축·단가 스냅샷) → 크레딧 잔액/차감 도메인(PG SoT·RLS) → pause 결선(ADR-0140) → 상한/캡 가드 → 정산 관측 표면. UI(잔액·사용 내역·충전)는 UXUI 트랙 별도.
