## ① 새 크기 절에 썩을 수 있는 수가 남았는가 — **없다**

절 전체에서 숫자를 전수로 뽑았다:

```
0건(size-5) · 0곳(사유 주석) · 12px · 16px×2 · 20px · 24px · size-3 · size-4 · size-5 · 획 2
```

**손으로 센 위반 수는 하나도 남지 않았다.** 사라진 것: `165곳` · `102곳` · `55곳` · `7곳` · 네 파일 목록. 남은 숫자는 전부 **규칙의 값**(12/16/20/24px, 획 2)이거나 **0** 둘이다. 그 둘은 성질이 다르므로 따로 판정한다.

| 남은 수 | 성질 | 판정 |
|---|---|---|
| "20px(`size-5`)는 레포에 **0건**이다" | **경계 주장** — 규칙 자체를 말한다. 위반이 생겨야 거짓이 되고, 위반을 잡는 것이 바로 리뷰가 할 일이다. 수리로는 깨지지 않는다 | ✅ 유지가 맞다. 이 0이 없으면 바로 다음 문장("두 번째 기본을 들이는 것은 이 절의 개정이다")이 근거를 잃는다 |
| "오늘 사유 주석은 **0곳**이다" | **잔량 0** — 누가 사유를 하나 달면(=수리) 거짓이 된다 | ✅ "오늘"이라는 시점 한정이 붙어 정직하다. §2.2가 "지금은 전부 rule-only"라고 적는 것과 같은 어법 |

그리고 절이 **자기 절제를 문장으로 적었다**:

> "**이 축을 세는 기계는 없고**(§5.3), 손으로 센 수는 여기 적지 않는다 — 세 경로 탓에 수가 곧 썩는다."

이것이 §5.3의 집필 규율("각 규칙 옆에 무엇을 재는가와 무엇을 안 재는가를 적는다")을 절 안에서 그대로 실행한 것이다. R2가 §5.5①을 근거로 권고한 1안이 문면대로 채택됐다.

## ③ M-1의 in-PR 몫 — **충족**

§5.3 아이콘 행이 R1에서 합성 트리로 초록 통과를 실증한 **네 경로를 전부** 이름 댄다:


"(둘 다 초록 통과 실증)"이라는 괄호까지 붙었다 — 근거가 규칙 옆에 붙는 이 문서의 규율에 맞다. 특히 `.ts` 항목은 형제 파일 `designSystem.test.ts:47`이 이미 이름 대어 둔 위험(`"` `.ts` 까지 — 프리플라이트가 `.tsx` 만 훑는 자리를 이 파일이 받는다`"`)과 같은 축이고, 이제 두 자리가 서로를 가리킨다.

**남은 가드 코드 확장은 적립이 맞다.** 오늘 위반 0건이고, 이 PR의 상품은 문서다. 코드를 R2·R3에서 동결한 판단은 옳았다 — 픽셀 무변화 주장을 세 번 재검증하게 만들지 않았다.

### 부수 확인 — 살아남은 수치는 안전한가

§5.3 아이콘 행은 접근성 잔량(`aria-hidden` 57곳 / 인접 레이블 없는 36곳)을 **여전히 수로** 적는다. 크기 축은 수를 버렸는데 여기는 남긴 비대칭이 옳은지 따로 검산했다 — **옳다.**

- `aria-hidden`은 **태그 속성 하나**라 세 경로 문제가 없다. 지역 const로 오는 자리(`FeedRow`·`WorkConsoleRoute`)도 속성 자체는 태그에 그대로 보인다.
- 이름으로 안 보이는 유일한 자리(`ExecutionTierField:122 <Icon>`)는 `aria-hidden="true"`를 **갖고 있어** 결손 집계에 애초에 들어가지 않는다. 즉 모수가 165든 166이든 **결손 절대수 57/36은 흔들리지 않는다.**
- 84b4d537에서 재측정: 57 / 36 / QuickSwitcher 12 — R2와 동일. ✅

크기는 못 세고 접근성은 셀 수 있다 — 그 갈림을 문서가 명시하진 않았지만, 두 절이 실제로 다르게 행동하는 근거는 실재한다.

## ④ N-5 · N-6 (Nitpick, 머지 무관)

**N-5.** "직접 지정이 대다수이고 **나머지는** 버튼 프리미티브의 `[&_svg]:size-4`가 진다" — 16px 153자리는 `직접 102 + Button 계약 48 + 지역 const 3`이다. 그 셋은 `FeedRow.tsx:35`다:

```
const className = cn("size-4", TONE_CLASS[tone]);
if (kind === "approval") return <ShieldAlert className={className} />;   // ×3
```

바로 다음 절이 "지역 const"를 세 경로 중 하나로 이름 대므로 독자가 틀린 행동을 하진 않는다. 다만 **지역 const 경로는 예외(12px)에만 있는 게 아니라 기본(16px)에도 있다** — "나머지는 부모 계약이거나 지역 const가 진다" 정도의 한 낱말이면 닫힌다.

**N-6.** §5.2 행이 "`public/**/*.svg` **전수**"라 적지만 `src` 쪽 스캔은 `*.test.tsx`를 뺀다. 옳은 동작이고, 같은 표의 **카피 행은 그 제외를 명시한다**(`*.test.ts(x)·*.d.ts 제외`). 표 안에서 어법을 맞추면 된다.
