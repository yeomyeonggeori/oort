1. **[중] D8 셀프호스트 파일 보관소 미연결** — 첨부 선택 즉시
   "파일 보관소가 연결돼 있지 않습니다. 서버 관리자에게 알리세요"(no-archive).
   클라 실패 상태 UX는 모범적으로 동작(원인+다음 행동+개별 지우기/모두 지우기).

   전 계열(M-1 표시 검증·M-2 전송·U-3 라이트박스)이 원천 불가**. 서버측 보관소
   구성(로컬 볼륨 옵션 or SELF_HOST 문서 명시)이 필요 — 티켓 후보로 원장 기록.
2. **[하] 이모지 피커 위치** — `fixed left-1/2 top-8`(상단 중앙 다이얼로그 문법)라

   일관·설계 의도이나(랜딩 design-review 통과), 앵커드 팝오버 전환은 후속 취향

+ 프록시(5173 — centrifugo 허용 오리진) + **socat `api` 브리지**(centrifugo 구독 프록시
`api:8080`→호스트 서버; compose 밖 서버로 리그를 짤 때의 함정 — 이것 없으면 WS는 붙되

## U-3 라이트박스 — E2E 종결 + 실결함 수리

- 업로드→발송→타임라인 이미지→라이트박스 종단 성립 (12, 13).
- **실결함(High) 발견·수리**: 라이트박스가 512px 좌측 스트립으로 렌더 —
  `cn()`의 tailwind-merge가 하우스 측정명을 몰라 `max-w-none` 오버라이드가
  스타일시트 순서에 지고 있었다. 수리=단어형 측정명 19종 전량 등록+정본 파싱
  가드 테스트(PR #1697, design-review PASS·Blocker 0·High 0 종결). 수리 후
  1440×941 풀스크린 실측 (14). Esc·다운로드 버튼 정상.
