# momo 개인정보처리방침 (초안 템플릿 — 법률 검토 전)

> **이 문서는 초안 템플릿이며 법률 자문이 아니다.** 게시 전 변호사 검토 필수.
> 게시 위치: 도메인 `https://<momo-domain>/privacy` (또는 GitHub Pages). App Store Connect URL + 앱 내 설정에 링크.
> 근거: Apple App Review Guidelines §5.1.1, 개인정보보호법(PIPA).

## 1. 수집하는 개인정보 항목
- 필수: 이메일(로그인/식별), 표시명, 워크스페이스/멤버십 정보.
- 서비스 이용 중 생성: 메시지 본문·첨부, 에이전트 작업 기록, 비용/감사 로그.
- 선택: (마케팅 동의 시) 알림 수신.
- 자동 수집: APNs 푸시 토큰(푸시 사용 시), 접속 로그(보안).

## 2. 수집·이용 목적
- 메신저 서비스 제공(메시지 송수신, 워크스페이스 격리).
- 에이전트(김인턴 등) 응답 생성 — 입력 메시지를 LLM 처리에 사용.
- 보안·부정이용 방지, 법령상 의무 이행.

## 3. 제3자 제공 / 처리위탁 (중요)

  - 제공 항목: 사용자가 에이전트에게 보낸 메시지 및 컨텍스트.
  - 목적: 에이전트 응답 생성.
